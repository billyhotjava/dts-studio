# Sprint-24: 报表资产生产器 + 业务对象问答器

**时间**: 2026-05  
**前缀**: RAO (Report Asset + Object QA)  
**状态**: IN_PROGRESS  
**目标**: 在 Sprint-23 自然语言导报表闭环之上，把 Agent 从“生成一段 SQL”升级为“优先复用报表资产、缺口生成候选 ADS、业务明细回到业务对象”的工作流。

## 背景

当前 Copilot 已能把自然语言问题转成 `REPORT_DRAFT`，并能优先使用 PRS 报花域的 dbt ADS/DWS 表。但业务现场还有两个缺口：

1. 经营类报表需要高效可信。已有 ADS/DWS 应直接复用；没有 ADS 时，Agent 应生成候选 ADS/dbt 模型草稿，而不是每次临时扫 DWD/ODS。
2. 明细和业务状态需要贴近原系统。用户问“采购配送记录状态分布”“某个字段有哪些值”时，不能只暴露裸 ODS 表，需要通过业务对象目录、字段画像和页面语义解释。

本 sprint 的路线：

```text
自然语言
  -> 资产路由
    -> 命中 L2 固定报表/大屏
    -> 命中 L1 ADS/DWS 报表草稿
    -> 缺口生成候选 ADS/dbt 模型
    -> 命中 L0 业务对象问答/字段画像
  -> 预览 / 保存 / 晋升 / 回到业务系统
```

## Feature 列表

| ID | Feature | Task 数 | 优先级 | 状态 | 说明 |
|----|---------|---------|--------|------|------|
| F1 | 资产生产与业务对象路由 | 5 | P0 | IN_PROGRESS | 建立 Agent 首层路由：报表资产优先、业务对象可问答 |

## 完成标准

- [ ] Agent Planner 能在同一问题中区分：已有报表资产、候选 ADS 生产、业务对象问答、受控动作提案。
- [ ] 已有 ADS/DWS 命中时不访问 ODS；没有 ADS/DWS 时输出候选 ADS/dbt 草稿和验证项。
- [x] 首批业务对象至少覆盖采购配送记录、采购汇总、库存、租赁账单、报花单据。
- [x] adminapi/adminweb 重点业务域已沉淀为对象资产图：报花、采购、项目、财务、仓库。
- [x] 前端 AI 报表页提供报表资产生产器与业务对象问答器入口，并有页面测试覆盖。
- [ ] 业务对象问答必须包含页面路径、主表/来源、关键字段、状态字典、默认时间字段、可回跳业务页面。
- [ ] 任何 ODS 访问都要标识为只读、源表排查或字段画像，不作为经营汇总默认口径。
- [ ] 报表草稿、候选 ADS 和业务对象回答都带 `dataSurface`、`qualityLevel`、`sourceRefs`。
- [ ] IT 验收覆盖 Golden Questions：经营 TOP、采购配送状态分布、无 ADS 新报表、ODS 字段画像。

## 非目标

- 不在本 sprint 直接实现业务写操作。
- 不自动把 Agent 生成的候选 ADS 发布到生产 dbt 项目。
- 不把 Copilot 变成大屏渲染器；可视化仍交给 BI/DTS，Copilot 负责表格化预览和资产管理。

## 风险与缓解

| 风险 | 缓解 |
|---|---|
| Agent 临时 SQL 污染报表资产 | 新报表先落草稿，候选 ADS 需人工确认后晋升 |
| ODS 字段缺少业务解释 | 通过业务对象目录补页面、状态、字段别名和默认时间 |
| DWD 生成 ADS 口径不一致 | 候选 ADS 必须输出 grain、metric、sourceRefs、tests |
| 查询源库影响业务系统 | 默认查询 DTS ODS/字段画像；业务库仅保留只读 Bridge |
