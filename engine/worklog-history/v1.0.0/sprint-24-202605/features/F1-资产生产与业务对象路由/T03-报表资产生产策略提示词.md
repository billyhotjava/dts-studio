# T03: 报表资产生产策略提示词

**优先级**: P0  
**状态**: READY  
**依赖**: T02

## 目标

让 Agent 在没有现成 ADS/DWS 时，不直接临时拼 ODS SQL，而是生成候选 ADS/dbt 模型草稿。

## 技术设计

`REPORT_DRAFT` prompt 增加策略：

- 已有 ADS/DWS：直接查询并生成报表草稿。
- 只有 DWD：输出候选 ADS 的 grain、metrics、dimensions、SQL、dbt tests。
- 只有 ODS：先转业务对象问答或字段画像，不默认经营汇总。

## 验证

- [ ] 无 ADS 问题的 prompt 包含候选 ADS 生成要求。
- [ ] 已有 ADS 问题不降级到 ODS。

## 完成标准

- [ ] Planner 元数据能标识 `L1_CANDIDATE_ADS`。
