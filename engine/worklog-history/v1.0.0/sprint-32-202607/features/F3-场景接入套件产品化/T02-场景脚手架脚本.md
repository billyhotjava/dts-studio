# F3/T02 场景脚手架脚本

**优先级**: P1
**状态**: DONE
**依赖**: F3/T01

## 目标

提供一条命令生成新场景骨架，降低新业务域接入成本。

## 技术设计

新增 `scripts/scaffold-scenario-kit.mjs`：

- 输入 `--scene-code`、`--domain-name`、`--owner` 等参数。
- 递归读取场景套件模板。
- 替换 `{{sceneCode}}` 等变量，包括文件名和文件内容。
- 支持 `--dry-run`、`--output-dir`、`--force`。
- 默认输出到 `assets/scenario-onboarding-kit/generated/<scene>`。

## 影响范围

- `scripts/scaffold-scenario-kit.mjs`
- sprint-32 `assets/scenario-onboarding-kit/templates/**`
