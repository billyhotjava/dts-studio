# F4/T02 多场景共存隔离验证

**优先级**: P1
**状态**: DONE
**依赖**: T01

## 目标

验证采购、报花 dbt mart 和库存新域并存时，Agent 不串域、不串物理表、不把未发布资产库占位当成已认证资产。

## 技术设计

- 使用真实 `copilot-ai` 内部 chat 接口生成 SQL。
- 使用 `copilot-analytics /api/dataset` 通过 Trino 联邦入口执行生成 SQL。
- 覆盖 4 类问题：
  - 采购：`看下2026年各个绿植的采购情况` -> `TPL-34` -> `mysql.rs_cloud_flower.t_purchase_price_item`
  - 报花销售：`查询2026年销售情况` -> `TPL-52` -> `public.xycyl_ads_flowerbiz_sale_summary`
  - 库存现量：`展示2026年库存现状` -> `TPL-53` -> `mysql.rs_cloud_flower.s_stock_info`
  - 低库存：`低库存预警` -> `TPL-54` -> `mysql.rs_cloud_flower.s_stock_info`

## 影响范围
