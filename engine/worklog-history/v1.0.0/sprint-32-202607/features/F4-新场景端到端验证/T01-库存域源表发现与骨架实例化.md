## 口径结论

- 库存统计优先用 `good_price_id` / SKU，不能只按 `good_name` 聚合。
- 库存成本需区分 `s_stock_info.out_cost`、`b_goods_price.cost_price` 和出入库明细 `price`。
- 入库、出库、库存三类状态字段不能共用一个枚举。
- 旧 `WH-LOW-STOCK-ALERT` fixed report 占位资产不能视为已认证库存资产。
