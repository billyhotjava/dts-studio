# T03: 联邦查询资源/超时/审计护栏

**优先级**: P1
**状态**: DONE
**依赖**: S30-F6

## 目标

给 Trino 联邦 native SQL 增加运行时边界：静态 guardrail 之外，所有执行路径都必须走统一运行 gate，避免固定报表、大屏预热等旁路绕过 `/api/dataset` 主路径。

## 技术设计

1. `QueryExecutionFacade.prepare()` 继续在 guardrail 前规范 SQL，保证 `/api/dataset` 能返回已补全的 `native_form.query` 和 `source_metadata`。
2. `DatasetQueryService.runNative()` 作为最终执行 gate，再次应用 `FederatedNativeSqlQualifier`，覆盖直接执行路径：
   - `DefaultFixedReportExecutionService`
   - `ScreenWarmupService`
   - 其他未来直接调用 `runNative` 的服务
3. 当前阶段只做 dbt Postgres catalog 补全：联邦 Trino 数据源且允许 `postgres` catalog 时，将 `FROM/JOIN public.xycyl_*` 改写为 `postgres.public.xycyl_*`。
4. 资源/审计后续扩展点保留在同一 gate：查询超时、结果上限、扫描量/内存上限、执行审计都应在 `QueryExecutionFacade`/`DatasetQueryService` 边界统一实现。
