# T02: 业务问句分类与意图词典

**优先级**: P0  
**状态**: DONE  
**依赖**: T01

## 目标

把业务用户自然语言拆成 Agent 可稳定识别的意图、业务域、报表类型和取数层级。

## 输出物

建议新增或更新：

- `dts-copilot-ai/src/main/resources/prompts/prs-report-intents.txt`
- `dts-copilot-ai/src/main/resources/semantic-packs/flowerbiz.json`
- 后续新增 `semantic-packs/prs-business-domains.json` 或拆成各域独立语义包。

## 意图分类

| 意图 | 说明 | 示例 |
|---|---|---|
| `FIXED_REPORT` | 已有固定报表、大屏、模板可直接打开 | “打开报花总览大屏” |
| `REPORT_DRAFT` | 需要生成新 SQL 和展示建议 | “按月统计租赁收入趋势” |
| `BUSINESS_DETAIL` | 查业务明细、状态、处理人、深链 | “这个项目有哪些待确认账单” |
| `BUSINESS_INSIGHT` | 基于报表结果生成建议 | “哪些客户需要催收跟进” |
| `ACTION_PROPOSAL` | 后续受控业务动作草稿 | “帮我生成催收待办” |

## 验证

- [x] 同义词覆盖业务人员常用词：租摆、报花、加摆、撤摆、换花、调拨、坏账、回收、月账、开票、回款。
- [x] 至少 50 条问句能人工归类到意图和业务域。
- [x] `FIXED_REPORT` 问句不会误走自由 SQL。
- [x] 明细/动作类问句不会误走 L1 汇总表。

## 完成标准

- [x] Planner 可以使用该词典输出稳定的业务域和响应类型。
