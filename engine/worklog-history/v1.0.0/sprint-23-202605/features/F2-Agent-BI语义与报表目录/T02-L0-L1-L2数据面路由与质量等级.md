# T02: L0/L1/L2 数据面路由与质量等级

**优先级**: P0  
**状态**: DONE  
**依赖**: T01

## 目标

让 Agent 在生成报表前先选择可信取数面，避免默认对业务库裸表做自由 NL2SQL。

## 路由规则

| 优先级 | 数据面 | 命中条件 | 结果 |
|---|---|---|---|
| 1 | L2 固定报表/大屏 | 问句包含“打开、查看、报表、大屏、租赁月报”等固定资产 | 返回固定报表或 screen |
| 2 | L1 dbt ADS/DWS | 趋势、排行、汇总、占比、同比、分布 | 生成 `REPORT_DRAFT` |
| 3 | L0 adminapi 只读 | 明细、当前状态、处理人、业务页跳转 | 调用只读 Bridge 或返回深链 |
| 4 | 受控探索 | 没有目录命中但属于白名单域 | 限制 SELECT + limit + 白名单 |

## 质量等级

| 等级 | 行为 |
|---|---|
| `HIGH` | 可直接生成正式报表和建议 |
| `MEDIUM` | 可生成报表，但必须显示口径/质量提示 |
| `LOW` | 只能探索和提示问题，不允许自动创建正式大屏或业务动作 |

## 验证

- [x] 固定大屏问句命中 L2。
- [x] 趋势/排行/汇总问句命中 L1。
- [x] 明细/状态/处理问句命中 L0。
- [x] 数据质量为 `LOW` 的报表不会出现“创建业务动作”入口。

## 完成标准

- [x] Planner 输出中包含 `dataSurface`、`qualityLevel`、`qualityNotes`。
