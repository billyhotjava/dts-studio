# F3: 自然语言导报表闭环

**优先级**: P0  
**状态**: DONE

## 目标

让业务用户在 Copilot 中输入自然语言后，能看到可运行的报表草稿，并能把草稿保存成查询、创建图表或加入大屏。

## Task 列表

| ID | Task | 优先级 | 状态 | 依赖 |
|----|------|--------|------|------|
| T01 | Copilot 报表入口与生成报表卡 | P0 | DONE | F2-T03 |
| T02 | `analysis_draft` 预览、保存、创建图表/大屏 | P0 | DONE | T01 |
| T03 | 报表解释、质量提示与业务建议卡 | P1 | DONE | T01, F2-T02 |

## 完成标准

- [x] 用户不需要进入 SQL IDE，也能从自然语言得到报表预览。
- [x] 报表草稿可以保存并二次编辑。
- [x] 保存后的图表可以复用到大屏。
- [x] 数据质量提示不被隐藏在说明文本里，而是在报表卡上可见。
