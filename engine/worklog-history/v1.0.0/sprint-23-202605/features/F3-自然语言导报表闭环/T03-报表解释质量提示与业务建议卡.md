# T03: 报表解释、质量提示与业务建议卡

**优先级**: P1  
**状态**: DONE  
**依赖**: T01, F2-T02

## 目标

让 Agent 不只给 SQL 和图表，还说明口径、可信度和下一步业务建议。业务反向指导在本 sprint 只到建议/草稿，不执行写动作。

## 输出要求

- 报表解释：指标含义、筛选条件、时间范围。
- 数据质量提示：缺失字段、低覆盖维度、可能的口径偏差。
- 业务建议：例如“待开票金额高的项目需要财务核验”“坏账高的客户建议复核合同和回款状态”。
- 动作边界：只展示“生成建议/待办草稿”，不直接执行业务写接口。

## 验证

- [x] `MEDIUM` 数据质量报表必须展示 `qualityNotes`。
- [x] `LOW` 数据质量报表不展示“创建业务动作”入口。
- [x] 建议卡能关联到报表草稿和证据 SQL。

## 完成标准

- [x] 报表结果可以自然延伸到业务建议，但不会越权执行业务动作。
