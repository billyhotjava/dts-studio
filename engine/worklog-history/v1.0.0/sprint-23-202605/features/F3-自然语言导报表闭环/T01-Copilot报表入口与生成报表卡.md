# T01: Copilot 报表入口与生成报表卡

**优先级**: P0  
**状态**: DONE  
**依赖**: F2-T03

## 目标

在 Copilot 对话中提供面向业务用户的“生成报表”体验，而不是只返回 SQL 文本。

## 交互要求

- 问句命中 `REPORT_DRAFT` 时渲染报表卡。
- 报表卡显示：标题、业务域、数据来源、质量等级、SQL 摘要、推荐图表。
- 操作按钮：预览、保存草稿、创建图表、加入大屏。
- 对 `MEDIUM` / `LOW` 数据质量显示醒目的口径提示。

## 验证

- [x] “生成今年租赁收入按月趋势”返回报表卡。
- [x] “打开报花总览大屏”返回固定大屏卡，而不是 SQL。
- [x] “这个项目有哪些待确认账单”返回明细/深链卡，而不是汇总图表。

## 完成标准

- [x] Copilot 中可以完成自然语言到报表卡的第一跳。
