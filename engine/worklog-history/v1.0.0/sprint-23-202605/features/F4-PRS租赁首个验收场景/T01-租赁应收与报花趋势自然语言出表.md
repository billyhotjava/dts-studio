# T01: 租赁应收与报花趋势自然语言出表

**优先级**: P0  
**状态**: DONE  
**依赖**: F2-T03

## 目标

把用户自然语言转成可运行的租赁/报花报表草稿，并默认支持 `2025-05-01` 至当前日期的分析窗口。

## 首批问句

1. “从 2025 年 5 月到现在，租赁收入按月趋势怎么样？”
2. “今年每个月加摆和撤摆金额分别是多少？”
3. “本月待审批报花单按类型统计。”
4. “坏账金额最高的客户和项目有哪些？”
5. “各项目本月报花金额排名。”
6. “各养护人本月处理工作量排行。”
7. “回收数据按项目和回收去向统计。”
8. “生成一张本月租赁运营周报。”

## 验证

- [x] 每条问句返回 `REPORT_DRAFT` 或明确的固定资产。
- [x] SQL 只访问白名单 ADS/DWS 或受控只读视图。
- [x] 报表结果携带 `qualityLevel`。
- [x] 默认时间窗口明确，不用含糊的“近期”。

## 完成标准

- [x] 租赁/报花域可以作为自然语言导报表的首个可演示闭环。
