# T03: 权威溯源信任分层

**优先级**: P1
**状态**: DONE
**依赖**: T01、sprint-27 F6

## 目标

复用 sprint-27 F6/F8 的 `trace.metricCaliber` 契约,让用户在对话中明确看到本次回答来自 dts-platform 已发布指标还是 AI 现生成 SQL。

## 落地

- `MessageList` 对含 `trace.metricCaliber.name` 的助手消息展示「来自平台指标 / 指标名 / 口径版本」。
- `InlineIndicatorPreview` 用 `trace.metricCaliber.ontologyRef ?? reportCode` 取平台指标值,并将 `formula/version/domain` 写入 Indicator artifact 的 trace。
- 退回 AI 现生成时后端不写 `trace.metricCaliber`,前端徽标自然消失。
