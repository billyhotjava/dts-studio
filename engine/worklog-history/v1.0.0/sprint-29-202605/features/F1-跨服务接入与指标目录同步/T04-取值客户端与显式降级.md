# T04: 取值客户端方法 + 显式降级

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标

封装 dts-platform 治理指标取值端点,让前端和后续 Agent 路由能以统一契约读取 dashboard/detail/drilldown,并在平台不可达时得到显式降级结果。

## 实现

- `dts-copilot-analytics/.../PlatformIndicatorClient` 已实现:
  - `getDashboard(days)`
  - `getDetail(indicatorId, days)`
  - `drilldown(indicatorId, dimension, period)`
- 失败场景返回 `ValueResponse(degraded=true, degradedReason=...)`,不抛裸异常到 UI。
- 返回值统一为 `cols/rows/timeGrain/mode/indicatorId`,直接对齐前端 `PlatformIndicatorValueResponse`。

## 验证

- `mvn -pl dts-copilot-analytics -Dtest=PlatformIndicatorClientTest,PlatformIndicatorResourceTest test`
- `mvn -pl dts-copilot-analytics test`

## 完成标准

- [x] dashboard/detail/drilldown 方法可调用。
- [x] 平台 5xx/不可达/未配置时返回显式降级。
- [x] 取值结果可被前端 `ChartRenderer`/`ArtifactCanvas` 消费。
- [x] Live contract 已补:dashboard/detail/drilldown 通过服务认证返回 HTTP 200 且 BFF `degraded=false`;`codex_sprint29_live_metric` 本地 fixture 已完成样本对账。
