# T03: 指标目录领域模型 + 语义层落位

**优先级**: P0
**状态**: READY
**依赖**: T02

## 目标

定义 copilot 内部的**指标目录领域模型**与缓存载体,把平台 `IndicatorDto` 转换为 copilot 自有的、面向**本地匹配 + 渲染**的 `IndicatorCatalogEntry`,并把目录注册进**语义层**,供 F3 指标优先路由本地匹配使用。

口径单一源仍在平台:copilot 只缓存目录的**定义/口径/维度/版本**元数据,不缓存口径计算逻辑、不重算。

## 技术设计

### 领域模型 `service/platform/IndicatorCatalogEntry`(record,对齐 `BusinessObjectCatalogService.BusinessObjectEntry` 风格)

从平台 `IndicatorDto` 映射(字段已在 `dts-platform/.../dto/IndicatorDto.java` 核实存在):

```java
public record IndicatorCatalogEntry(
        String id,              // 平台 UUID 字符串,取值时用
        String code,            // 唯一编码,缓存主键 / version 比对键
        String name,            // 展示名,匹配主信号
        String category,        // 分类
        String domain,          // 业务域,路由域对齐用
        String definition,      // 权威口径定义文本 → 命中后填口径芯片(sprint-27 F5)
        String expressionSql,   // 口径 SQL → 溯源展示(sprint-27 F6)
        String status,          // 恒为「已发布」(同步已过滤)
        String version,         // 口径版本,F5 变更提醒
        List<String> tags,      // 由平台 tags 字符串拆分(逗号/分号)
        List<String> dimensionFields,  // 由 dimensionFields 拆分 → drilldown 维度候选
        String dateColumn,
        String timeGrain,       // drilldown period 映射用
        String aggregationType,
        String measureField,
        String dataLevel,       // 密级标记(试用期机器账号绕过行列权限的提示位)
        String owner,
        List<String> matchKeywords  // 派生:name + code + tags + dimensionFields 归一化,供本地匹配
) { /* compact constructor 做 List.copyOf 防御性拷贝 */ }
```

转换器 `IndicatorCatalogMapper.fromPlatform(IndicatorDto)`:
- `tags` / `dimensionFields`:平台为单字符串(可能是逗号/JSON 数组),按 `,`/`;` 或 JSON 解析拆为 `List<String>`,解析失败降级为单元素列表,不抛异常。
- `matchKeywords`:聚合 `name`、`code`、`tags`、`dimensionFields` 做小写归一(对齐 `BusinessObjectCatalogService.normalize`),为 F3 评分匹配预备。
- `IndicatorDto` 无显式同义词字段(设计第 10 节已标风险),匹配质量后续依赖 F3 接 copilot 同义词字典(sprint-8 NV-07),本模型只负责把可匹配文本汇齐。

### 缓存载体 `service/platform/IndicatorCatalogStore`(`@Component`)

- 持有 `volatile List<IndicatorCatalogEntry> snapshot`(不可变快照)+ `Instant lastSyncAt` + `SyncResult lastResult`。
- 写:`replaceAll(List<IndicatorCatalogEntry>)` 由 T02 调用,copy-on-write 原子替换。
- 读(供 F3/T05):
  - `List<IndicatorCatalogEntry> all()`(返回 `List.copyOf` 或不可变引用)。
  - `Optional<IndicatorCatalogEntry> byCode(String code)` / `byId(String id)`。
  - `boolean isReady()`(空目录时 F3 应禁用指标路由,全退回生成 SQL)。
  - `CatalogStatus status()`(`lastSyncAt` / `entryCount` / `stale` 标记,供 T05 暴露)。

### 语义层落位

- 与 `SemanticPackService`(`@PostConstruct` 装载语义包)、`BusinessObjectCatalogService`(内存目录 + 评分)并列,**指标目录作为新的语义来源**注册。
- 不改 `SemanticPackService` 的静态包装载逻辑;F3 路由时**并列查询** `IndicatorCatalogStore`(最高优先目标)与现有对象/视图目录,优先级 `已发布指标 > 视图/mart > 现生成 SQL`(设计 D3,F3 实现判优先级,本 Task 只保证目录可被查询)。
- 提供只读视图给 F3:`IndicatorCatalogStore.all()` 即语义层指标条目来源。

## 影响范围

- **新增**:`service/platform/IndicatorCatalogEntry.java`、`IndicatorCatalogMapper.java`、`IndicatorCatalogStore.java`、`CatalogStatus.java`(record)。
- **修改**:T02 `IndicatorCatalogSyncService` 改为写入 `IndicatorCatalogStore`(替换占位)。
- **不改**:`SemanticPackService`、`BusinessObjectCatalogService`(指标目录是并列新来源,不侵入)。
- **dts-platform**:零改码。

## 验证

- **单元测试**(`IndicatorCatalogMapperTest`、`IndicatorCatalogStoreTest`):
  - `fromPlatform` 正确映射核心字段;`tags`/`dimensionFields` 多种格式(逗号串 / JSON 数组 / 空)均能安全拆分。
  - `matchKeywords` 含 name/code/tags/dimensionFields 归一化结果。
  - `IndicatorCatalogStore` 替换后 `byCode`/`byId`/`all` 一致;空目录 `isReady()=false`。
  - 并发读写拿到完整快照。
- **集成**:T02 同步一轮后,`store.all()` 条数 == 平台已发布指标数;`it/README.md` 贴一条真实指标映射前后对照。
