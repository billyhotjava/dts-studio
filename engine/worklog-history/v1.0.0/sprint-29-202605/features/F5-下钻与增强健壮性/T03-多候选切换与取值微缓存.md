# T03: 多候选切换与取值微缓存

**优先级**: P2
**状态**: DONE
**依赖**: F3、F4

## 落地

- 多候选切换复用 F4 的 `metric` 可改芯片;后端按候选 name/code 重新选择指标,`__fallback_generated__` 跳过指标路由。
- analytics `PlatformIndicatorClient` 为 `dashboard/detail/drilldown` 取值增加可配置 TTL 微缓存: `DTS_PLATFORM_VALUE_CACHE_TTL_SECONDS`,默认 60 秒。
- 微缓存只缓存成功取值;平台失败仍返回 `degraded:true`,不缓存错误。

## 验证

- `mvn -pl dts-copilot-analytics -Dtest=PlatformIndicatorClientTest test` PASS,覆盖 detail value TTL 缓存。
- `mvn -pl dts-copilot-ai -Dtest=AssetBackedPlannerPolicyTest test` PASS,覆盖切候选与退回。
