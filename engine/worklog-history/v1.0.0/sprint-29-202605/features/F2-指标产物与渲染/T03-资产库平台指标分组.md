# T03: 资产库「平台指标」分组

**优先级**: P0
**状态**: DONE
**依赖**: T01, T02, T04

## 目标

在资产库内提供 Sprint-29 的最短可演示闭环:浏览 dts-platform 已发布治理指标和本地 Metric Lens,支持搜索、显式降级、单窗口取值预览,并能把指标问题交给 Agent BI。

根据 Sprint-28 的单窗口决策,本 Task 不恢复右侧预览画布;指标取值在资产库卡片内构造 `type:'indicator'` artifact,用 `ArtifactCanvas` 直接渲染。

## 实现

- `AssetLibraryPage` 增加 `metrics` tab 和 `/assets?tab=metrics` 路由状态。
- `MetricAssetsPanel` 并发读取 `analyticsApi.listPlatformIndicators()` 与 `analyticsApi.listMetricLens()`,任一侧失败时保留另一侧资产并展示降级提示。
- 平台指标卡提供「预览取值」:调用 `getPlatformIndicatorDetail(indicatorId, 30)`,成功后构造 `indicatorArtifact` 并在当前卡片中渲染 `ArtifactCanvas`;降级/失败时显示错误提示。
- 指标卡提供「交给 Agent」:跳转 `/agent-bi?source=asset-library-metric&metric=...&prompt=...&submit=1`,由工作台单窗口消费 query prompt。
