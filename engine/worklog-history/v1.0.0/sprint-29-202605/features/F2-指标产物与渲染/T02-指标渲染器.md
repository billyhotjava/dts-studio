# T02: 指标渲染器

**优先级**: P0
**状态**: READY
**依赖**: T01(Indicator 产物类型)

## 目标

让 sprint-27 F4 的 `ArtifactCanvas` 能渲染 `type:'indicator'` 产物——**完全复用**现有 `ChartRenderer`(echarts 封装)与 `DataTable`,不新增任何图表实现。按指标 `timeGrain` / `dimensionFields` 选择呈现:

- 有时间序列(`timeGrain` + 时间列)→ 趋势图(line/area)。
- 纯明细 / 多维聚合 → 明细表格。
- `display` 落到 echarts 不支持的形态 → **回退 `DataTable`**(对齐 `ChartRenderer` 既有「unsupported → 表格」行为),绝不空屏或报错。

同时在画布头部展示指标身份(名称/口径版本)作为权威标识,与 AI 现生成产物区分(F4/F6 的完整芯片/溯源后续做,本期先有最小可视标识)。

## 技术设计

文件:`/opt/prod/prs/source/dts-copilot/dts-copilot-webapp/src/components/canvas/ArtifactCanvas.tsx`

### 1. `renderArtifactBody` 增 indicator 分支

现有 `renderArtifactBody` 按 `artifact.type` 分 chart/table/report。在最前面加 indicator 分支(loading/error 态对齐现有 `CanvasState`):

```tsx
if (artifact.type === "indicator") {
	if (loading) return <CanvasState title="正在向 dts-platform 取指标值…" />;
	if (error) return <CanvasState title={resolveErrorMessage(error)} tone="error" />;
	return <IndicatorArtifactBody artifact={artifact} />;
}
```

### 2. `IndicatorArtifactBody`(本文件内新增)

核心是「选渲染器」——直接委派给现有组件,不重写图表:

```tsx
function IndicatorArtifactBody({ artifact }: { artifact: Artifact }) {
	const meta = artifact.spec.indicator;
	const dataset = artifact.spec.dataset ?? null;
	const display = artifact.spec.display ?? "table";

	// 趋势/标量/明细统一交给 ChartRenderer;它内部已做
	// table/pivot/unsupported → DataTable 的回退,天然满足「不支持回退表格」。
	return (
		<div className="artifact-canvas__indicator">
			{meta ? <IndicatorCaliberBar meta={meta} /> : null}
			<ChartRenderer
				data={dataset}
				display={display}
				settings={artifact.spec.settings}
				className="artifact-canvas__chart"
			/>
		</div>
	);
}
```

> 关键:`ChartRenderer` 已内置 `case 'table'|'pivot'|default → <DataTable>`、以及 combo/waterfall/funnel/scatter/map 等「not yet supported → DataTable」回退。因此**回退表格无需在本 Task 重新实现**——只要 T01 的 `resolveIndicatorDisplay` 产出 line/area/scalar/table 之一,落不到支持分支也会安全回退。明细模式直接传 `display="table"` 即可走 `DataTable`。

### 3. `IndicatorCaliberBar`(最小权威标识)

本期最小实现:展示「指标名 · 口径 vN」+ 密级(若有),作为「这是平台权威指标」的可视标记。完整可改芯片/退回交互留 F4。

```tsx
function IndicatorCaliberBar({ meta }: { meta: IndicatorArtifactMeta }) {
	return (
		<div className="artifact-canvas__caliber" title={meta.definition}>
			<span className="artifact-canvas__caliber-badge">平台指标</span>
			<span>{meta.name}</span>
			{meta.version ? <span className="artifact-canvas__caliber-ver">口径 {meta.version}</span> : null}
			{meta.stale ? <span className="artifact-canvas__caliber-stale">缓存值</span> : null}
		</div>
	);
}
```

### 5. 样式

文件:`src/components/canvas/Canvas.css` —— 新增 `.artifact-canvas__indicator` / `__caliber*` 的最小样式(沿用现有 token,不引入新调色板)。`__caliber-stale` 用提示色与「平台指标」徽标区分。

### 渲染选择矩阵(由 T01 `resolveIndicatorDisplay` 决定 `display`,本 Task 只消费)

| 指标取值形态 | display | 实际渲染组件 |
|---|---|---|
| 时间序列(timeGrain+时间列) | `line` / `area` | `ChartRenderer` → LineChart/AreaChart(echarts) |
| 单点标量(1行1数值列) | `scalar` | `ChartRenderer` → ScalarChart |
| 多维明细 / 下钻表 | `table` | `ChartRenderer` → DataTable |
| 不支持/未知 | 任意 | `ChartRenderer` 内置回退 → DataTable |

## 验证

- 单测:传入带时间序列 dataset + `display:'line'` 的 indicator 产物 → 渲染出 ChartRenderer(查 chart-container);传 `display:'table'` → 渲染 DataTable。
- 单测:传 `display` 为不支持值(如 `'funnel'`)→ 仍渲染出 DataTable(回退),不抛错。
- 单测:`meta.version` 存在 → 口径条显示「口径 vN」;`meta.stale` 为 true → 显示「缓存值」标记。
- 单测:loading/error 态走 `CanvasState`,与 chart/table 分支一致。
- 视觉:口径条与画布既有头部不冲突,沿用现有 token。
