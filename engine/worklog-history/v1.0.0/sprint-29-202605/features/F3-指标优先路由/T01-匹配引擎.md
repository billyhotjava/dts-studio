# T01: 指标匹配引擎(IndicatorMatcherService)

**优先级**: P0
**状态**: READY
**依赖**: F1(已发布指标目录已同步进本地缓存/语义层)

## 目标

对 F1 同步来的**本地指标目录(仅 `status=已发布`)**做问句匹配,输出候选指标列表 + 置信度,供 T02 路由判定使用。匹配在**本地目录**完成(不为每次问数跨服务),复用 copilot 现有同义词字典。对应设计 §5 第 1 条「匹配」与 §6「匹配复用同义词字典」。

## 技术设计

新增 `dts-copilot-ai/src/main/java/com/yuzhi/dts/copilot/ai/service/copilot/IndicatorMatcherService.java`(`@Service`,与 `IntentRouterService`/`TemplateMatcherService` 同包同层,便于 T02 注入)。

- **输入数据源**:注入 F1 的 `IndicatorCatalogSyncService`(本地缓存),取 `status=已发布` 的指标列表(每项含 `IndicatorDto` 字段:`code/name/category/definition/expressionSql/status/version/tags/aggregationType/dimensionFields/dateColumn/timeGrain` 等)。F1 若提供本地缓存 record(如 `IndicatorCatalogEntry`),本服务消费之;若 F1 仅暴露 `IndicatorDto`,本服务在内部建轻量索引。
- **匹配信号(按设计 §5 列举的字段)**:对每个已发布指标,用 `name / code / tags / definition / category / dimensionFields` 与用户问句做匹配:
  - `name` / `tags` / `dimensionFields` 命中 → 强信号(精确包含或同义词归一后包含)。
  - `code` 命中 → 强信号(用户直接报代码)。
  - `definition` / `category` 命中 → 弱信号(关键词覆盖)。
- **同义词归一**:复用 `SemanticPackService#getSynonyms(domain)`(sprint-8 NV-07,从 `semantic-packs/*.json` 加载 `term -> field` 映射)。把问句中的术语先经同义词映射展开,再与指标字段匹配,缓解 `IndicatorDto` 无显式同义词字段的问题(设计 §10 已标该风险)。domain 归一沿用 `AssetBackedPlannerPolicy#normalizeSemanticDomain` 的同名规则(`settlement/green→project`、`task/curing/pendulum→flowerbiz`),保证字典域键一致。
- **置信度**:仿照 `IntentRouterService` 的「绝对命中数优先、命中比率其次」打分思路,产出 `[0,1]` 置信度;定义两个阈值常量(`HIGH_CONFIDENCE_THRESHOLD`、`MEDIUM_CONFIDENCE_THRESHOLD`),区分**高置信单命中 / 多候选·中置信 / 低置信**三档(对应 T02 与设计 §5 第 3 条乐观执行合流)。阈值为命名常量,不硬编码散落。
- **输出契约(record)**:
  ```
  record IndicatorMatch(String code, String name, String category, String definition,
                        String expressionSql, String version, double confidence,
                        List<String> matchedSignals)
  record IndicatorMatchResult(List<IndicatorMatch> candidates, Confidence tier)
  enum Confidence { HIGH, MEDIUM, LOW, NONE }
  ```
  `candidates` 按 confidence 降序;`tier=NONE` 表示无命中(T02 据此直接退回)。
- **边界与降级**:
  - F1 目录为空 / 未就绪(stale-while-revalidate 也无缓存)→ 返回 `tier=NONE`,记 `log.debug`,不抛异常(指标路由临时禁用,设计 §7 降级)。
  - 仅遍历 `status=已发布`,显式过滤其他状态,避免把草稿/下线指标误命中。
  - 匹配为纯内存计算,无外部调用、无副作用(不可变输出)。
