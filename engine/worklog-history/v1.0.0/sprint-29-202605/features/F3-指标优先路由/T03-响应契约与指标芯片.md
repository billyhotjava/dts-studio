# T03: 响应契约与指标芯片

**优先级**: P0
**状态**: DONE
**依赖**: T02、F1

## 目标

把 `PUBLISHED_INDICATOR` 路由结果写进 sprint-27 F8 的既有响应契约,让前端不用新增协议即可区分「平台权威指标」与「AI 现生成」。

## 落地

- `ConversationPlannerService.ResponseKind` 新增 `PUBLISHED_INDICATOR`。
- `ConversationPlan` 携带 `metricCaliber`(`name/formula/domain/version/ontologyRef`)。
- `CopilotChatContract.buildTrace` 将平台指标口径写入 `trace.metricCaliber`。
- `CopilotChatContract.buildAssumptions` 生成 `key=metric`、`editable=true` 的指标假设芯片,options 包含候选指标和 `__fallback_generated__`「退回 AI 现生成」。
- `AgentExecutionService` 仅在存在 `metric` override 时把 request context 交给 planner,避免把其它 assumption 行为扩大化。

## 验证

- `mvn -pl dts-copilot-ai -Dtest=AssetBackedPlannerPolicyTest,CopilotChatContractTest test` PASS。
- `mvn test` PASS: `dts-copilot-ai` 191 tests, `dts-copilot-analytics` 106 tests。
