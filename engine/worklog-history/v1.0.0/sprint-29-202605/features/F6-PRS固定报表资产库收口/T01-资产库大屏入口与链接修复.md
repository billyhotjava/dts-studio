# T01: 资产库大屏入口与链接修复

**优先级**: P0
**状态**: DONE
**依赖**: Sprint-28 F1 fixedReport query

## 目标

修复资产库看板 tab 中 PRS 固定报表/大屏资产缺失和链接无效的问题。

## 技术设计

- `DashboardsPage` 拉取固定报表目录时从 `limit=12` 调整为 `limit=100`,避免后端按更新时间截断后只拿到 DBT split 子报表。
- 固定报表快捷入口改用 `buildFixedReportQuickStartItems`,该函数内部基于 `buildFixedReportAssetGroups` 折叠资产组,只返回主报表。
- 新增 `isScreenBackedFixedReport`,用 `targetObject=screen.*`、`assetKind=DBT_SCREEN_TABLE`、`dataSourceType=DBT_SCREEN` 或 `sourceRefs` 判断 PRS 大屏资产。
- T01 初始收口时快捷入口跳转 `buildFixedReportOpenPath` -> `/agent-bi?fixedReport=...`,复用 Sprint-28 已接通的工作台 query 消费路径。
- T03 进一步确认 PRS 是可视化大屏资产后,`buildFixedReportOpenPath` 已改为 PRS 模板直接跳转 `/screens/{screenId}/preview`;非 PRS 固定报表仍保留 Agent fixedReport 降级/执行路径。
