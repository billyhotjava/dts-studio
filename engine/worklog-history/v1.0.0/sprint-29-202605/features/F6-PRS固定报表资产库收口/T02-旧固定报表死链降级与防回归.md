# T02: 旧固定报表死链降级与防回归

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标

修复资产库/Agent 对话中旧固定报表模板产生的死链,避免用户点击 `WH-LOW-STOCK-ALERT` 等已归档模板后进入“未找到固定报表模板”的空白错误态。

## 根因

- 运行库里 `WH-LOW-STOCK-ALERT`、`WH-STOCK-OVERVIEW`、`FIN-AR-OVERVIEW`、`PROC-SUPPLIER-AMOUNT-RANK` 等旧模板仍保留历史记录,但 `archived=true`。
- 前端候选固定报表和产物模型只按 templateCode 合成 `/agent-bi?fixedReport=...`,没有区分“当前可运行资产”和“历史归档模板”。
- `AgentWorkspacePage` 对固定报表 404 只显示错误态,没有降级为业务对象/主题表分析。

## 技术设计

- 新增 `shared/fixedReportAvailability.ts`,统一判断当前 Agent 可直接打开的固定报表链接。
- PRS 花卉租赁模板继续生成 `/agent-bi?fixedReport=...`;旧 WH/FIN/PROC 模板保留展示文本和 templateCode,但不生成可点击 href。
- `MessageList` 不再在 `candidate.href` 为空时自行 fallback 合成 fixedReport 链接。
- `AgentWorkspacePage` 遇到旧模板 404 时自动生成普通 Agent prompt,提示“未在资产目录发布或已归档”,并继续走业务对象/dbt 分析。
- `Artifact` 模型不再为旧模板附加 `reportHref`,避免产物卡片继续暴露死链。
