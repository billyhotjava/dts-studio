# T02: 钉到看板

**优先级**: P1
**状态**: READY
**依赖**: F4 画布、F5 回答、T01(产物→卡片;钉看板的最小单元是卡片)

## 目标

让画布「当前产物」一键钉进看板:点击动作行 `[钉到看板]` → 选已有看板或新建看板 → 把产物作为一个布局项追加进看板并持久化;成功后可跳转到该看板。

## 技术设计

### 前置:产物 → 卡片

看板的成员是卡片(`DashboardCard.card`)。因此钉看板前需先有卡片 id:

- 若产物已存为卡片(T01 已执行或产物自带 cardId),直接复用其 `cardId`。
- 否则先复用 T01 的 `buildCardPayloadFromArtifact` + `createCard` 静默建卡(可不弹命名,用产物标题),拿到 `cardId` 再钉。

### 接口签名(均已存在,真实)

```ts
// src/api/modules/dashboard.ts
analyticsApi.listDashboards(): Promise<DashboardListItem[]>          // GET  /api/analytics/dashboard
analyticsApi.getDashboard(id): Promise<DashboardDetail>             // GET  /api/analytics/dashboard/{id}
analyticsApi.createDashboard(body: unknown): Promise<DashboardDetail> // POST /api/analytics/dashboard
analyticsApi.saveDashboard(body: unknown): Promise<DashboardDetail>   // POST /api/analytics/dashboard/save
```

### 布局项结构(真实类型,`src/api/types.ts`)

```ts
type DashboardCard = {
  // ...
  row?: number; col?: number; size_x?: number; size_y?: number;
  card?: CardListItem | null;
};
type DashboardDetail = DashboardListItem & {
  dashcards?: unknown[];
  ordered_cards?: DashboardCard[];
};
```

`DashboardGrid`(`components/DashboardGrid/DashboardGrid.tsx`)把 `DashCard{ row,col,size_x,size_y }` 转成 react-grid-layout 的 `{ i,x,y,w,h }`(`x=col, y=row, w=size_x, h=size_y`)。追加新卡片需算一个不重叠的落位。

### 追加布局项算法(抽纯函数)

`appendCardToDashboardLayout(existing: DashboardCard[], cardId, { size_x=12, size_y=6 }): DashboardCard[]`

- 默认尺寸取半宽(看板默认 24 列,取 `size_x=12`)。
- 落位:取现有项中 `max(row + size_y)` 作为新项 `row`,`col=0`,避免重叠(简单纵向追加策略,后续可优化)。
- 返回新数组(不可变,spread),作为 `ordered_cards` 提交。

### 流程

1. 点 `[钉到看板]` → `<PinToDashboardModal>`:
   - 选已有看板(`listDashboards()` 列表)或「+ 新建看板」(输入名称 → `createDashboard({ name })`)。
2. 取目标看板 `getDashboard(id)` → 现有 `ordered_cards`。
3. 确保产物有 cardId(见「前置」);`appendCardToDashboardLayout` 追加。
4. 按现有 `DashboardEditorPage` 保存形态持久化:`saveDashboard({ dashboard: { id, name, description, collection_id }, dashcards: nextDashcards })`。不得只传 `{ id, ordered_cards }`,避免漏传后端必需的 `dashboard.id` 包装字段。
5. 成功后提示并给「打开看板」链接(`/dashboards/{id}`)。

> 注:`saveDashboard` 的确切 payload 字段以 `DashboardDetailPage` / `DashboardEditorPage` 现有保存逻辑为准,实施时对齐其字段,避免漏传必填项。
