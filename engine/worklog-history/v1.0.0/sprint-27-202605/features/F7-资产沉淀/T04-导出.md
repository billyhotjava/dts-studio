# T04: 导出

**优先级**: P1
**状态**: READY
**依赖**: F4 画布、F5 回答(产物携带结果数据集与图表)

## 目标

让画布「当前产物」一键导出:点击动作行 `[导出]` → 选格式 → 下载。本期支持两种:**结果集 CSV** 与 **图表图片(PNG)**。建立一个统一的导出/下载工具,消除现有 `screens/**` 里重复的 `createObjectURL + a.download` 样板。

## 技术设计

### 现状盘点(真实)

- **没有公用导出工具**。下载样板在多处重复:`screens/components/ScreenHeader/hooks/useExportHandlers.ts` 的 `downloadBlob(blob, fileName)`、`ScreenExportPage.tsx`、`ScreenVersionComparePanel.tsx`、`ScreenCompliancePanel.tsx`、`TemplateGallery.tsx` 等均各自 `URL.createObjectURL` + `a.download` + `revokeObjectURL`。
- report-factory 有服务端导出 URL:`getReportRunExportUrl(id, format: 'html'|'markdown')`(仅报表运行,不适用即席结果)。
- 无 CSV 序列化工具,无前端图表转图片工具。

### 新增统一下载工具

新增 `src/lib/download.ts`:

```ts
export function downloadBlob(blob: Blob, fileName: string): void  // 统一 createObjectURL/a.download/revoke
export function downloadText(text: string, fileName: string, mime: string): void
```

把 `screens/**` 现有重复样板逐步收敛到此工具(本 Task 至少新建并在画布导出处使用;screens 处的替换可作为顺带清理,不强制全量)。

### CSV 导出(结果集)

新增纯函数 `src/lib/csv.ts`:

```ts
export function rowsToCsv(columns: string[], rows: unknown[][]): string
```

- 字段含逗号 / 引号 / 换行时按 RFC 4180 加引号转义;首行为列名。
- 数据来源:产物的结果集(`CardQueryResponse` 形态:列定义 + 行数据,由 F5 产物提供)。
- 导出:`downloadText(rowsToCsv(cols, rows), \`${标题}.csv\`, 'text/csv;charset=utf-8')`。
- 文件名带 BOM 视需要(中文 Excel 兼容)可加 `﻿` 前缀。

### 图表图片导出(PNG)

- 画布图表由 F4/F5 渲染。导出策略二选一,实施时按图表渲染技术定:
  1. 若图表渲染到 `<canvas>`(如 echarts):取实例 `getDataURL()` / `canvas.toBlob()` → `downloadBlob`。
  2. 若为 SVG/DOM:用 `html-to-image` / `dom-to-image` 类库或将 SVG 序列化为 blob(参考 `ScreenExportPage.tsx` 对 SVG 的处理)。
- 优先复用图表库自带的导出能力,避免引额外重依赖;若必须引库,记到 Feature 备注并评估包体(遵循 web 性能预算)。

### UI 交互

- F4 画布动作行消费统一 `CanvasActionEvent { action: "export", artifact }`;F7 提供一个小菜单(`ui` 现有 Button + 简单 dropdown / Modal):`导出 CSV` / `导出图片`。
- scalar/无表格结果禁用 CSV;无图表结果禁用图片导出。

## 影响范围

- 新增 `src/lib/download.ts`(统一下载)、`src/lib/csv.ts`(CSV 序列化纯函数)。
- F4 `CanvasActions`:消费统一 `CanvasActionEvent { action: "export", artifact }` + 格式选择 UI。
- 可选清理:`screens/**` 多处重复的 `downloadBlob` 收敛到 `lib/download.ts`(非阻塞性,作为顺带 refactor)。
- 若图表导图需引库:`package.json` 新增依赖(需在 PR 说明并评估包体)。
