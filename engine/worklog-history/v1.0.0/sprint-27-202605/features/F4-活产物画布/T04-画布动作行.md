# T04: 画布动作行(CanvasActions)

**优先级**: P0
**状态**: DONE
**依赖**: T02

## 目标

实现画布顶部动作行 `CanvasActions`,渲染 [存为卡片] [钉到看板] [</> SQL·溯源] [导出] 四个按钮。**本 Task 只出 UI + 派发统一事件**,不实现任何具体动作——SQL·溯源 触发交 **F6**(溯源信任面板),存卡片 / 钉看板 / 导出 交 **F7**(资产沉淀)。定义清晰的事件契约,让 F6/F7 接线即用。

> 设计依据:§4 状态二右侧「顶部动作:[存为卡片] [钉到看板] [</> SQL·溯源] [导出]」、§6「结果卡动作行」、决策 D3(⑤写回仅预留接口)。

## 技术设计

### 1. 动作事件契约(在 `src/types/artifact.ts` 或 `src/components/canvas/canvasActions.ts` 定义)

```ts
export type CanvasActionType =
  | "save-card"      // 存为卡片 → F7
  | "pin-dashboard"  // 钉到看板 → F7
  | "trace-sql"      // </> SQL·溯源 触发 → F6
  | "export";        // 导出 → F7

export interface CanvasActionEvent {
  action: CanvasActionType;
  artifact: Artifact;   // 当前画布产物(含 spec.generatedSql / sourceRefs 供溯源/导出消费)
}
```

### 2. 组件签名(新建 `src/components/canvas/CanvasActions.tsx`)

```tsx
interface CanvasActionsProps {
  artifact: Artifact | null;                       // 当前产物;为空时按钮禁用
  onAction: (event: CanvasActionEvent) => void;    // 唯一出口,派发给上层
  disabledActions?: CanvasActionType[];            // 可选:按产物 type 禁用部分动作
  busyAction?: CanvasActionType | null;            // 可选:某动作进行中(F7 接线后控制)
}
```

- 四个按钮复用现有 `ui/Button`(参考 `DataTable.tsx` 中 `Button` 的引入路径 `../ui/Button/Button`),图标 + 文案。`</> SQL·溯源` 用代码风格图标。
- 点击 → `onAction({ action, artifact })`;`artifact == null` 时全部禁用。
- 按产物 type 自动收敛可用动作:`type: 'report'` 可禁用「存为卡片」(报表已是沉淀产物),通过 `disabledActions` 由上层控制,本组件只渲染。
- hover/focus/active 态遵循既有按钮设计,键盘可达。

### 3. 与 F6 / F7 的接线边界

- 本 Task **不 import** `analyticsApi` 的存卡片/看板接口,**不 import** `TracePanel`。
- 上层(F5 工作台 / `CanvasPanel`)接收 `onAction` 后:
  - `trace-sql` → 由 **F6** 打开溯源面板(消费 `artifact.spec.generatedSql` / `targetView` / `dataSurface` / `sourceRefs`)。
  - `save-card` / `pin-dashboard` / `export` → 由 **F7** 调用资产接口。
- 本 Task 在测试里用 mock `onAction` 验证派发,即满足完成标准;真实落地由 F6/F7 各自的 Task 完成。
