# T02: 画布渲染容器(ArtifactCanvas)

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标

实现 `ArtifactCanvas` 组件:接收一个 `Artifact`(或 `artifactId` + store),按 `Artifact.type` 选择渲染器——`chart` 走 `charts/ChartRenderer`(echarts-for-react 封装),`table` 走 `DataTable`,`report` 走报表占位/跳转,并提供缺产物 / 加载中 / 错误三种空态。画布只依赖 `Artifact` 数据,不感知对话消息(解耦)。

## 技术设计

### 1. 组件签名(新建 `src/components/canvas/ArtifactCanvas.tsx`)

```tsx
interface ArtifactCanvasProps {
  artifact: Artifact | null;     // 当前要渲染的产物(由 T03 从 store.current 传入)
  loading?: boolean;             // 流式生成中
  error?: unknown;               // 生成失败
  className?: string;
  style?: React.CSSProperties;
}
```

画布只接 `Artifact`,不接 `AiAgentChatMessage`,落实 T01 的解耦契约。

### 2. 按 type 分发渲染

- `type === "chart"`:渲染 `<ChartRenderer data={spec.dataset} display={spec.display ?? 'table'} settings={spec.settings} loading={loading} error={error} />`。`ChartRenderer` 内部已封装 echarts 的 `LineChart`/`BarChart`/`PieChart`/`AreaChart`/`ScalarChart`(经 `echarts-for-react`),并对 `combo`/`waterfall` 等不支持类型自动回退到 `DataTable`,本组件直接复用其分发逻辑,不重复造轮子。
- `type === "table"`:渲染 `<DataTable cols={spec.dataset.cols} rows={spec.dataset.rows} />`(`DataTable` 自带排序/分页/截断)。
- `type === "report"`:渲染报表产物占位卡(报表名 `spec.reportCode` + 「用 AI 报表打开」跳转 `spec.reportHref`,对齐 `copilotFixedReportMessage.ts` 的 `getFixedReportShortcut` 产出的 href 形态 `/agent-bi?fixedReport=...`)。本期不内嵌完整固定报表渲染(P2 完整承接),仅给入口。

### 3. 空态 / 加载态 / 错误态

- **无产物**(`artifact == null` 且非 loading):居中占位「右侧画布会在这里钉住你正在看的产物」,弱化引导。
- **加载中**(`loading`):对 chart/table 透传给 `ChartRenderer` 的 loading(已有 Spinner);report 自渲染骨架。
- **错误**(`error`):对 chart/table 透传给 `ChartRenderer`(已有错误态);其它类型自渲染错误卡 + 错误信息。
- 复用既有 token/类名风格(参考 `ChartComponents.css` 的 `chart-container__loading/__error/__empty`),新增 `Canvas.css` 仅补画布外框/留白。

### 4. 渲染纯度

`ArtifactCanvas` 为展示型组件(presentational):无数据加载副作用,产物由上层(T03 / F5)经 store 注入;`React.memo` + 按 `artifact.id` 做浅比较,避免追问时无关重渲染。
