# T01: 聊天响应契约扩展

**优先级**: P0
**状态**: DONE
**依赖**: F3-T00

## 目标

扩展 agent 聊天响应契约，让 F5/F6 能从同一份消息对象中消费口径假设、置信度、澄清项和结构化溯源；后台未返回时前端必须降级不报错。

## 技术设计

契约新增可选字段：

```ts
interface CopilotAssumption {
  key: string;
  label: string;
  value: string;
  editable?: boolean;
  options?: { value: string; label: string }[];
  sourceHint?: string;
}

interface CopilotClarification {
  key: string;
  question: string;
  options: { value: string; label: string }[];
}

interface CopilotTrace {
  metricCaliber?: {
    name: string;
    formula?: string;
    domain?: string;
    version?: string;
    ontologyRef?: string;
  };
  sources?: Array<{ table: string; fields?: string[]; role?: string }>;
  sql?: string;
}
```

落点：

- `AiAgentChatMessage` 增 `assumptions?: CopilotAssumption[]`、`confidence?: number`、`clarifications?: CopilotClarification[]`、`trace?: CopilotTrace`。
- `CopilotStreamEvent.done` 增同名字段。
- 同步响应、SSE `done`、`getAiAgentSession` 会话恢复必须语义一致。
- `aiChatCompatibility` / session proxy 归一化函数透传未知字段或显式映射，不丢数据。
