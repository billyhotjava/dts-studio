# T04: 输入器 + 语音整合

**优先级**: P0
**状态**: READY
**依赖**: T02

## 目标

把对话脊柱底部的输入区整合为独立的 `Composer` 组件:文字输入(自适应高度 + 回车提交 / Shift+回车换行 / 输入法防误提交)、语音转写回填(`VoiceInputButton`)、发送 / 停止 / 打断重发(`copilotStreamControl.resolveCopilotSendAction`)、可编辑性守卫(`copilotComposerState.canEditCopilotComposer`),行为与拆分前一致。

## 技术设计

### `Composer.tsx` 组成(迁自 `CopilotChat.tsx` L907~L972 + L1304~L1376)

输入区 + 上方的会话条与数据源条一并归入 `Composer`(或拆为 `Composer` + `ComposerSessionBar`,视行数 < 800 行裁量):

- **会话条**:`select`(会话下拉,新对话 + `sessions` 列表)+「新建」+「删除」按钮。下拉数据与 onChange(`handleNewChat` / `setSessionId`)来自 T05 的会话状态,经 props 传入。
- **数据源条**:`databases.length > 0` 时渲染数据源 `select`(`selectedDbId` / `setSelectedDbId`),来自 T05。
- **文字输入**:`textarea ref={inputRef}`,`onChange` 内自适应高度(`el.style.height = 'auto'` → `Math.min(scrollHeight, 160)`);`onKeyDown` 用 `shouldSubmitCopilotInputOnEnter`(`copilotInputBehavior`,已处理 `Enter` / `shiftKey` / `isComposing` / `keyCode===229`)判定提交,提交后重置高度。`disabled={!canEditComposer}`,placeholder 按 `copilotEnabled` 切换。
- **语音**:`<VoiceInputButton onTranscript={(text, isFinal) => isFinal && setInput(prev => prev ? `${prev} ${text}` : text)} disabled={!canEditComposer || sending} />`,语义不变。
- **新对话按钮**:输入区左侧 `+` 按钮(`handleNewChat`)。
- **发送 / 停止按钮**:`sendAction = resolveCopilotSendAction({ copilotEnabled, requestInFlight: sending, input })`,`mode === 'stop'` 时点 `handleStopStreaming`,否则 `handleSend`;`label` / `disabled` 由 `sendAction` 决定(`send` / `stop` / `interrupt-and-send` 三态)。

### Props 契约(展示组件保持纯)

`Composer` 不持有 send/stream 状态,全部由 `ConversationThread` 经 props 注入:

```
interface ComposerProps {
  // 输入
  input: string;
  onInputChange: (value: string) => void;
  inputRef: RefObject<HTMLTextAreaElement>;
  onSubmit: () => void;            // → handleSend
  onStop: () => void;              // → handleStopStreaming
  onNewChat: () => void;
  onVoiceTranscript: (text: string, isFinal: boolean) => void;
  // 状态
  copilotEnabled: boolean;
  canEditComposer: boolean;        // canEditCopilotComposer(...)
  sending: boolean;
  sendAction: CopilotSendAction;   // resolveCopilotSendAction(...)
  // 会话条 / 数据源条
  sessions: AiAgentChatSession[];
  sessionId: string | null;
  onSelectSession: (id: string | null) => void;
  onDeleteSession: () => void;
  databases: DatabaseListItem[];
  selectedDbId: number | null;
  onSelectDatabase: (id: number | null) => void;
}
```

`canEditComposer` 与 `sendAction` 在容器层计算(纯函数,来自 `copilotComposerState` / `copilotStreamControl`),`Composer` 只读。

### 行为保真要点

- `inputRef` 仍由容器持有(`promptRequest` 的 prefill 路径需要 focus + 设高,见 T05/容器),`Composer` 接收同一 ref。
- 自适应高度上限 160px、回车提交后重置高度的 `requestAnimationFrame` 逻辑保留。
- 语音只在 `isFinal` 时回填,且以空格拼接已有文本,语义不变。
- CSS 类名沿用 `copilot-chat__input-area` / `copilot-chat__input` / `copilot-chat__send-btn` / `copilot-chat__session-bar` / `copilot-chat__db-bar` 等,避免视觉回归。
