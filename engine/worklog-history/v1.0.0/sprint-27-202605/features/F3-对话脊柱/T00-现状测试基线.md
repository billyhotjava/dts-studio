# T00: 现状测试基线

**优先级**: P0
**状态**: READY
**依赖**: 无

## 目标

在删除旧 `/agent-bi` 页面、改造工作台壳、拆分 `CopilotChat` 之前，先把现有聊天主链路固化成可重复运行的基线测试，作为 F1/F3/F5 后续重构的回归闸门。

## 技术设计

本 Task 只补测试与最小纯函数抽取，不改变产品行为、不删除路由、不调整布局。

基线覆盖四条真实风险路径：

1. **发送守卫**：空输入、未启用 Copilot、发送中/流式进行中时不重复发起。
2. **SSE 事件归并**：`session` / `reasoning` / `token` / `tool` / `done` / `error` 对消息状态的影响可用纯 reducer 测试。
3. **停止与打断重发**：复用 `resolveCopilotSendAction`，锁住 `send` / `stop` / `interrupt-and-send` 三态。
4. **渲染契约**：消息区、输入区、`InlineSqlPreview`、`TracePanel`、`FeedbackButtons`、`VoiceInputButton` 的关键挂载点有结构断言，避免拆分时丢功能。

基线先基于当前 `src/components/copilot/CopilotChat.tsx` 建立；F3-T01/T02 拆分后再把断言目标迁移到 `ConversationThread` / `MessageList` / `Composer`，但行为断言保持同一套。
