# T03: 起手芯片

**优先级**: P0
**状态**: READY
**依赖**: T01（首屏与发起契约已落地）

## 目标

在冷启动首屏大输入框下方提供「起手芯片」，治冷启动「不知道能问什么」：高频问题芯片（如「本月各项目利润」「报花趋势」）点击即发起对应查询；固定报表跳转芯片（如「打开报花月报」）点击做简单跳转或直接发起对应查询。

> P1 范围：固定报表芯片只做简单跳转 / 直接发起对应查询；固定报表的模板化完整承接（对话内引用）在 P2（见 spec §9 分期注）。

## 技术设计

- 新建 `src/components/copilot/cold-start/StarterChips.tsx` + `starterChipsModel.ts`：
  - **高频问题芯片**：数据源复用 `WelcomeCard` 的现有体系——优先 `analyticsApi.listSuggestedQuestions(limit)`，失败/为空时回退到 `welcomeCardModel.ts` 的 `DEFAULT_WELCOME_GROUPS` / `AGENT_REPORT_BUSINESS_GUIDE`（已含「本月各项目利润」「报花趋势」类问题）。在 `starterChipsModel.ts` 内提取 `buildStarterChips(suggestions)`：从分组里挑选 N 个高频问题压平为 `{ id, label, prompt }[]`，复用 `buildWelcomeSuggestionGroups`，不重复造数据。
  - **固定报表跳转芯片**：少量固定项（如「打开报花月报」），类型区分 `kind: 'question' | 'fixed-report'`：
    - `question`：点击调用 T01 的发起回调 `onSubmit(prompt)` 直接发起查询。
    - `fixed-report`：P1 行为二选一——①`react-router` 跳转到对应固定报表路由（若 F1 保留了 `/fixed-reports` 入口）；②直接 `onSubmit("打开报花月报…对应查询语")` 走对话发起。优先「直接发起对应查询」以保持单入口体验。
  - 芯片为 `<button type="button">`，键盘可达，hover/focus/active 有设计态（不只默认样式）。
- 与首屏衔接：`ColdStartHome` 把 T01 的 `onSubmit` 透传给 `StarterChips` 的 `onPick(prompt)`；固定报表跳转用注入的 `onNavigate(path)` 或 `useNavigate`。
- 数据拉取放在首屏层（或 `StarterChips` 内 `useEffect`），与 `WelcomeCard.tsx` 同样的容错：异常静默回退到默认芯片，不阻塞首屏渲染。

## 影响范围

- 新增：`src/components/copilot/cold-start/StarterChips.tsx`、`starterChipsModel.ts`、`StarterChips.test.tsx`、对应样式（并入 `cold-start.css` 或独立）。
- 复用（不改）：`src/components/copilot/welcomeCardModel.ts`（`DEFAULT_WELCOME_GROUPS` / `buildWelcomeSuggestionGroups`）、`src/pages/agent-reports/agentReportQuickStarts.ts`（`AGENT_REPORT_BUSINESS_GUIDE`）、`analyticsApi.listSuggestedQuestions`。
- 修改：`ColdStartHome.tsx` 接入 `StarterChips` 并透传发起/跳转回调。
