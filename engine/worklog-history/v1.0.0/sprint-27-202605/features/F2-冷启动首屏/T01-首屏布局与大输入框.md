# T01: 首屏布局与大输入框

**优先级**: P0
**状态**: DONE
**依赖**: F1（工作台双栏壳与空态插槽）

## 目标

新建 `ColdStartHome` 组件作为工作台空对话态的首屏：居中一个大输入框（占位「问一句，或说一句…」），用户提交即发起会话进入对话脊柱（F3）。这是 F2 其余 Task（语音 T02、起手芯片 T03、三张卡 T04）的承载容器。

## 技术设计

- 新建目录 `src/components/copilot/cold-start/`：
  - `ColdStartHome.tsx`：首屏根组件。结构（语义化 HTML）：
    ```
    <section className="cold-start" aria-labelledby="cold-start-title">
      <h1 id="cold-start-title">…欢迎语…</h1>
      <ColdStartComposer ... />        // 大输入框（本 Task）
      <StarterChips ... />             // T03 插槽
      <ColdStartCards ... />           // T04 插槽（三张卡）
    </section>
    ```
  - `ColdStartComposer.tsx`：大输入框。用 antd `Input.TextArea`（`autoSize={{ minRows: 2, maxRows: 6 }}`），`placeholder="问一句，或说一句…"`，右下角放发送按钮 + 语音按钮槽位（T02 接入）。`Enter` 发送、`Shift+Enter` 换行（参考 `CopilotChat.tsx` 第 1341 行 `handleSend` 的键盘处理）。
  - `cold-start.css`：居中布局（首屏垂直居中、最大宽度约束、留白节奏），令牌化间距/字号，不硬编码重复色值。
- **发起会话契约**：`ColdStartHome` 接收 `onSubmit(text: string): void` 回调。提交时去空白校验（空串不发起）。
  - 与 F3 衔接方式（二选一，按 F3 实际拆分定）：①工作台壳直接把 `CopilotChat.handleSendText` 透传为 `onSubmit`（首选，零事件耦合）；②若壳与对话脊柱跨组件树，则复用现有 `dispatchAiQuickAsk(text)`（`src/components/ai/AiQuickAsk.tsx`，派发 `dts:ai-quick-ask`，`CopilotChat.tsx` 已监听该事件并走 `handleSendText`）。
  - 提交后由壳层切换空态 → 对话态（首屏退场逻辑属 F1 壳/ F3，本 Task 只负责回调与去空白）。
- 复用 / 参考：`WelcomeCard.tsx`（欢迎语与气质）、`AiQuickAsk.tsx`（`dispatchAiQuickAsk` 发起契约）。受控输入用 `useState`，遵守不可变更新。
- 工作台空态接入：在 F1 的工作台空态插槽处渲染 `<ColdStartHome onSubmit={...} />`，当且仅当当前无活跃会话/空对话时显示。
