# T04: 三张卡数据接入

**优先级**: P1
**状态**: DONE
**依赖**: T01（首屏容器已落地）

## 目标

为冷启动首屏的三张卡接入真实数据：⚠ 主动信号（P1 用规则化简单提醒占位，完整版主动洞察在 P3）、↻ 继续上次会话（读会话历史）、📌 我的资产（看板数 / 卡片数计数）。三张卡让用户在开口前先「看见有什么」与「上次到哪了」。

> P1 范围：主动信号卡只做规则化简单提醒占位，不接监控/检测/调度（完整版主动洞察见 spec §7③、P3 Sprint-3）。

## 技术设计

新建 `src/components/copilot/cold-start/ColdStartCards.tsx`，内部三张子卡，统一加载/空/错误态，使用 antd `Card` 但按 design 令牌定制（避免默认模板感）。数据逻辑抽到 `coldStartCardsModel.ts` 便于单测。

- **📌 我的资产卡**：并行调用 `analyticsApi.listDashboards()`（→ `DashboardListItem[]`）与 `analyticsApi.listCards()`（→ `CardListItem[]`），展示 `dashboards.length` 看板数 + `cards.length` 卡片数。点击进入 F7 资产库（注入 `onNavigate` / `useNavigate`）。两请求并行（`Promise.all`），互不阻塞首屏首绘（卡片内独立 loading）。
- **↻ 继续上次会话卡**：调用 `copilotApi.listAiAgentSessions(limit)`（→ `AiAgentChatSession[]`，含 `id` / `title` / `lastActiveAt`），取最近一条非空会话展示标题 + 相对时间。点击回到该会话：复用 `src/components/copilot/copilotSessionFocus.ts` 的 `requestCopilotSessionFocus(buildCopilotSessionFocusRequest({ sessionId, question: title }))`（派发 `dts-copilot:focus-session`，由 F3 对话脊柱监听并恢复）。
  - 用 `copilotSessionBootstrap.ts` 的 `shouldRestorePersistedCopilotSession(detail)` 思路过滤纯打招呼会话（若拿到 detail）；列表级先按是否有标题/非空过滤，提取 `pickResumableSession(sessions)` 纯函数。
- **⚠ 主动信号卡（P1 占位）**：`coldStartCardsModel.ts` 内 `buildPlaceholderSignals(assets, sessions)` 用规则生成简单提醒（如「你有 N 个看板、M 张卡片」「上次会话『…』未完成，继续？」），不调用任何监控/检测接口。预留 `signals: ColdStartSignal[]` 数据结构，便于 P3 替换为真实主动洞察。无可生成提醒时卡片优雅降级（提示「暂无新信号」）。
- 全部接口异常静默降级（参考 `WelcomeCard.tsx` 容错），不阻塞首屏与输入框；每张卡独立 loading skeleton。
- 会话存储：若 F1/F3 已有本地会话游标（如 lastSessionId），「继续上次」优先读它再回落到 `listAiAgentSessions`；否则仅用接口。

## 影响范围

- 新增：`src/components/copilot/cold-start/ColdStartCards.tsx`、`coldStartCardsModel.ts`、`ColdStartCards.test.tsx`、样式。
- 复用（不改）：`analyticsApi.listDashboards` / `listCards`（`src/api/modules/dashboard.ts`、`card.ts`）、`copilotApi.listAiAgentSessions`、`src/components/copilot/copilotSessionFocus.ts`（`requestCopilotSessionFocus` / `buildCopilotSessionFocusRequest`）、`copilotSessionBootstrap.ts`（`shouldRestorePersistedCopilotSession`）。
- 修改：`ColdStartHome.tsx` 接入 `ColdStartCards` 并注入导航回调；如引入本地会话游标，touch 对应会话存储工具（F1/F3 产物）。
