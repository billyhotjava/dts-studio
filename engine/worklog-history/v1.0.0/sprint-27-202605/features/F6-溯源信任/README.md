# F6: 溯源信任面板

**优先级**: P1
**状态**: READY
**依赖**: F4 活产物画布（动作行）、F5 乐观回答（常驻口径芯片）、F8 后台契约（trace / correction 桩）

## 目标

把现有 `TracePanel` 从「消息内浮动/内嵌的推理过程折叠块」扶正为一等公民的**溯源面板**：由画布动作行的「`</>` SQL·溯源」按钮触发（抽屉/侧栏），集中展示**命中口径**（来自本体 + 口径版本）、**数据来源**（表/字段）、**生成 SQL**，并提供「⚑口径不对？纠正」入口。让 NL2SQL 结果「看得到用了哪张表/哪个口径」，从不可信变可信（对应 spec §3 第 4 个卡点、§6、决策 D8）。

本期范围（spec D8 / 第二里程碑前置）：
- 关键口径芯片由 **F5 常驻结果卡**，本 Feature 不重复实现常驻芯片；
- **完整 SQL / 溯源默认按需展开**，不默认占屏；
- 「纠正」本期**只做 UI + 反馈采集**，回流到 NL2SQL 评测集 / 本体草稿（对接 sprint-26 adminapi 写回）**仅留接口桩**，完整回流在 P2（spec 第二里程碑「纠正即学习」）。
