# T02: 旧列表路由收敛到 `/assets?tab=`

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标

把旧列表入口统一到资产库,让同一类资产只有一个列表 URL。

## 技术设计

- 在 `routes.tsx` 增加列表 redirect 组件:
  - `/dashboards` -> `/assets?tab=dashboards`
  - `/questions` -> `/assets?tab=cards`
  - `/collections` -> `/assets?tab=collections`
- 保留创建、详情、编辑路由:
  - `/dashboards/new`, `/dashboards/:id`, `/dashboards/:id/edit`
  - `/questions/new`, `/questions/:id`, `/questions/:id/edit`
  - `/collections/:id`
- 更新导航和 public breadcrumb 中对列表入口的引用。
