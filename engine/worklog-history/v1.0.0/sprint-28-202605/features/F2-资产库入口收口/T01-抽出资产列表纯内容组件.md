# T01: 抽出资产列表纯内容组件

**优先级**: P0
**状态**: DONE
**依赖**: F1

## 目标

让资产库 tab 嵌入的是列表内容而不是整页,避免 `PageContainer` / `PageHeader` 嵌套。

## 技术设计

- 从 `DashboardsPage`、`CardsPage`、`CollectionsPage` 中抽出纯列表组件或增加 `embedded` 模式。
- `AssetLibraryPage` 只渲染资产库自己的 `PageHeader`,tab 内渲染纯列表。
- 保留原页面用于详情返回和独立访问时的标题。
