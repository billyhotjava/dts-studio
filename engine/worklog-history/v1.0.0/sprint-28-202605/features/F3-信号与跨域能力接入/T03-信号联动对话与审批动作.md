# T03: 信号入口联动对话与审批动作

**优先级**: P1
**状态**: DONE
**依赖**: T02

## 目标

从真实信号进入对话脊柱,并在存在 linked action 时复用 Sprint-27 已接入的审批面板。

## 技术设计

- `SignalsView` 点击信号后回调给 `AgentWorkspacePage`。
- `AgentWorkspacePage` 生成 `source=agent-workspace-signal`、`submit=true` 的 `CopilotPromptRequest`,prompt 包含信号标题、说明、来源和 `linkedActions`。
- linked action 不在前端伪造审批卡;继续复用对话返回的 pending action 驱动 `ApprovalPanel` 与 `useCopilotApproval`。

## 影响范围

- `dts-copilot-webapp/src/components/copilot/signals/SignalsView.tsx`
- `dts-copilot-webapp/src/components/copilot/ApprovalPanel.tsx`

- `dts-copilot-webapp/src/pages/AgentWorkspacePage.tsx`
