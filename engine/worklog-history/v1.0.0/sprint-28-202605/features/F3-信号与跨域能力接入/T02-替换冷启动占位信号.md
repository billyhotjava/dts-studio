# T02: 替换冷启动占位信号

**优先级**: P1
**状态**: DONE
**依赖**: T01

## 目标

移除或隔离 `buildPlaceholderSignals()` 对真实业务预警的冒充,让冷启动首屏只展示真实 signals 或明确的空态。

## 技术设计

- `ColdStartCards` 不再渲染“主动信号”卡。
- `buildPlaceholderSignals(...)` 保留兼容签名但固定返回空数组。
- 导航保留“信号”入口,进入 `/agent-bi?view=signals` 后由真实 API 视图负责加载或显示受控错误/空态。
