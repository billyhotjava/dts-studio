# T02: 口径回归测试网

**优先级**: P1
**状态**: BLOCKED
**依赖**: T01

## 目标

建立可重跑的口径回归网,对高危问句断言其路由/口径不越界,作为后续所有建模"不退化"的对照线(延续 sprint-26 F0/T03 基线风格)。

## 技术设计

- 整理"口径陷阱问句集"tsv:如"本月收入多少"(须拆链不混 SUM)、"坏账金额"(不计入收入)、"应收 vs 实收"(三级金额选列)、"库存成本"(加权平均 vs 指导价)等。
- JUnit/脚本断言:planner 对这些问句给出拆分/澄清/正确口径标签,而非静默混合。
- 对 F4 财务 mart 的关键聚合补 dbt test / SQL 断言(两链分别 SUM、含税vs不含税)。

## 影响范围

- `dts-copilot-ai/src/test/.../copilot/`(新建口径回归测试)
- `it/sql/`(陷阱问句集 tsv)
- dbt test(财务模型)

## 验证

- [ ] 口径回归测试可离线跑且绿
- [ ] 邻近 planner 回归不退化

## 完成标准

- [ ] 口径回归网绿,九条铁律中可断言的项有显式用例
