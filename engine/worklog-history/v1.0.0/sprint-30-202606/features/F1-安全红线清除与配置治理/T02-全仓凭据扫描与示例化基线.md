# T02: 全仓凭据扫描与示例化基线

**优先级**: P0
**状态**: DONE
**依赖**: 无

## 目标

建立可重跑的凭据扫描脚本与基线,确保 `docs/sql`、`adminapi/docker`、`dts-airflow/dags` 等位置不再出现明文密码/密钥,并把敏感 SQL/配置示例化。

## 技术设计

- 编写扫描脚本(正则:password=、Devops123、私钥头、token、连接串内联口令等),输出命中清单。
- 对历史 dump(`rs_cloud*.sql` 等)确认不含真实凭据;含则示例化或移出版本库。
- 沿用 AGENTS.md「docs/api-config、docs/sql、keystore 视为敏感示例」约定,补 `.gitignore` 与 `*.example` 模式。
- 把扫描脚本接入 it/ 作为可重跑校验。

## 影响范围

- 新增 `it/` 凭据扫描脚本;`.gitignore`/示例文件
- docs/sql、docker、dags 配置
