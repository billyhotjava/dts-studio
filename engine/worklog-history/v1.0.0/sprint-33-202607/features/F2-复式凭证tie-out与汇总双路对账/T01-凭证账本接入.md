# T01: 凭证账本接入（借=贷 复式作为汇总锚）

**优先级**: P0
**状态**: DONE
**依赖**: F1-T01

## 目标

把已过账凭证（最强 oracle）接入对账体系：凭证天然 借=贷、已绑业务单号，是验证汇总正确性的会计级锚点。

## 技术设计

- 凭证结构（已核实）：主表 `f_voucher` 含 `code`、`biz_code`、`biz_type`、`account_priod`；明细 `f_voucher_item` 含 `voucher_code`、`subject_id`、`debit_amount`、`credit_amount`、`status`。
- 接入只读视图：凭证按 业务单号 / 账期 / 凭证号 / 科目 聚合，供对账查询。可经 `VoucherController.list/listByCodes/listVoucherItems/getcountItems` 或其 ODS 镜像。
- **凭证内一致性自检**：任意凭证 / 凭证子集 `SUM(debit)==SUM(credit)`；本任务落地 `VoucherLedgerTieoutService` 的可重复样本校验。
- 明确"只读"：凭证是真相，copilot/对账绝不写凭证。

## 影响范围

- 凭证只读接入（端点或 ODS 镜像）+ 聚合视图
- 产出 `assets/voucher-tieout-mapping.md`（业务单/科目 ↔ 报表口径映射）
- 机器化资产：`governance/voucher-ledger-tieout-mapping.v1.json`、`VoucherLedgerTieoutRegistry`、`VoucherLedgerTieoutService`
