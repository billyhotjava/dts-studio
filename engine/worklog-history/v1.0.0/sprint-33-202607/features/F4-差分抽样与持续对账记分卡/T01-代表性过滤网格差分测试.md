# T01: 代表性过滤网格差分测试

**优先级**: P1
**状态**: IN_PROGRESS
**依赖**: F1, F2

## 目标

利用应用系统报表端点本身支持同样过滤（项目/月份/日期区间），对一个代表性过滤网格逐组调 oracle 端点 + copilot，断言相等——用真实 oracle 覆盖"自定义条件"的实测维度（与 F3 不变量的"任意条件证明"互补）。

## 技术设计

- **网格设计**：维度 = 项目（含全部/单项目）× 月份（跨年/单月/季度）× 日期区间（边界：月初月末、跨月）× 链（租摆/售赠坏）。分层抽样取代表组，非笛卡尔全展开。
- **差分**：每组 oracle 端点结果 vs copilot 结果，按维度比对，到分相等。
- **边界专项**：日期区间闭开区间（`>= 月初 AND < 次月初`）、折扣=1、空结果集、跨年。
- 复用 F1 对账 harness + F2 黄金 SQL，扩展为网格驱动。

## 影响范围

- 产出 `it/test_f4_differential_grid.sh` + 网格定义 + 证据
- 关联 oracle 端点（带过滤参数）与 copilot 财务路径

## 当前进度

- 已落地 `FinanceDifferentialGridRegistry`：机器化读取 `finance-differential-grid-cases.v1.json`，并强制绑定 F2 的 summary reconciliation case，防止链路/指标/维度漂移。
- 已落地 `FinanceDifferentialGridService`：按 `sliceId + projectId + accountPeriod` 比对 copilot/oracle 金额，支持 `matched`、`empty matched`、缺单边、金额差异、链路/指标错配、重复网格格子的失败输出。
- 已固化 2 组本地代表性网格：租摆结算折后实收、售赠坏应收；边界标签覆盖月边界、跨年、折扣=1、跨月、空结果。
- 未完成：真实 adminapi/oracle 端点参数、真实项目样本、`/api/dataset` copilot 结果与 live oracle 端点双路取数尚未接线。
