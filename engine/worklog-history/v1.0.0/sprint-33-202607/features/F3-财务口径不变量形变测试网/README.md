# F3: 财务口径不变量/形变测试网

**优先级**: P0
**状态**: DONE

## 目标

回答最难的命题：copilot 的**各种自定义查询条件**数据如何证明正确。无穷过滤组合无法穷举，但有一类"对任意过滤条件都必须成立的性质"（metamorphic invariants）——验证这些 = **证明性质**而非抽查。验证不变量 + 静态口径 guardrail，使一个从没见过的过滤组合即便无法预知正确值，只要满足全部不变量就被证明没踩已知错误模式。

## 8 条财务口径不变量（对任意过滤条件成立）

| # | 不变量 | 来源（口径铁律） |
|---|--------|------------------|
| 1 | 任意凭证子集 `SUM(debit)==SUM(credit)` | 复式记账 |
| 2 | 名义 ≥ 应收折前 ≥ 折后实收 ≥ 0 | 三级金额（陷阱#3） |
| 3 | 已回款 ≤ 折后实收 | 回款语义 |
| 4 | `SUM(全集) == Σ SUM(任意完整分区)`（按月之和=全年、按项目之和=全部） | 加和性 |
| 5 | 子条件结果 ⊆ 全集结果（行/额单调不增） | 单调性 |
| 6 | 租摆链(a_month_accounting) 与 售赠坏链(a_sale_account) **不出现在同一 SUM** | 两条结算链（陷阱#2） |
| 7 | 收入聚合排除坏账 receivable | 坏账是损失非收入（陷阱#2） |
| 8 | `a_sale_account + a_month_accounting` 必去 source_type=8 重叠 | 双重计数（陷阱#4） |
