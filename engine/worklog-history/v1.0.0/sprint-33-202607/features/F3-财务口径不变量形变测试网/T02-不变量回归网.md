# T02: 不变量回归网（对任意条件断言）

**优先级**: P0
**状态**: DONE
**依赖**: T01, Sprint-31 F4

## 目标

把结果级不变量做成对**随机/代表性过滤条件**都断言成立的回归网——这是"自定义条件可证明正确"的工程化落点，接入 Sprint-31 F4 回归网。

## 技术设计

- **形变测试（metamorphic）**：对同一基础问题施加变换，断言不变量保持：
  - 加和性：`Σ 按月(filter+month=m)` == `全年(filter)`（#4）
  - 单调性：`filter ∧ 额外条件` 的额/行 ≤ `filter`（#5）
  - 三级序/回款序：任意 filter 下 #2/#3 成立
  - 借=贷：任意凭证子集 #1 成立
- **条件采样**：项目 × 月份 × 日期区间 × biz_type × 状态 的随机/分层采样（非穷举），每组跑 copilot 出结果并校验不变量。
- 失败即定位到违反的不变量 + 触发 filter，产出可复现用例。
- 入 CI gate，与 Sprint-31 F4 共网。
