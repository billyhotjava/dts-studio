# T01: 8 条不变量机器可检规格（正/反例）

**优先级**: P0
**状态**: DONE
**依赖**: Sprint-31 F1（口径规则化）

## 目标

把 8 条财务口径不变量编码为机器可检规格，每条带可执行判定 + 正例（应通过）+ 反例（应违规），作为 T02 回归与 T03 静态拦截的统一输入。

## 技术设计

规格 `assets/finance-invariants.v1.json`，每条：
- `id`、`statement`、`appliesTo`（凭证/月对账/售账/聚合结果）、`check`（可执行表达）、`positiveExample`、`negativeExample`、`severity`。
- 两类判定：
  1. **结果级**（对查询结果集断言）：#1 借=贷、#2 三级序、#3 回款≤折后、#4 加和性、#5 单调性、#7 收入排坏账。
  2. **SQL 级**（对生成 SQL 静态断言，供 T03）：#6 两链不混 SUM、#8 source_type=8 去重。
- 复用并扩展 Sprint-31 F1-T03 的 `caliber-rules`，财务不变量作为其财务子集；不另立体系。

## 影响范围
