# T03: 持续评估记分卡

**优先级**: P1
**状态**: DONE
**依赖**: T02

## 目标

把黄金集和形变测试结果汇总成可读 scorecard，作为发版和回归判断依据。

## 技术设计

- 记分维度：route pass、SQL pass、data layer pass、evidence pass、tieout pass。
- 输出：总分、失败 case、降级原因、最近一次运行时间。
- 与 route telemetry 关联，优先扩展高频弱路径问题。

## 影响范围

- IT evidence。
- dashboard/debug endpoint。
- release checklist。

## 已完成

- 已落地 `Nl2SqlAccuracyGoldenSetScorecardService`，可汇总总数、通过数、通过率、健康状态和失败原因。
- 已覆盖 `PASS`、L0 profile 回退、应用 MySQL 回退、形变漂移四类门禁。
- 已落地 `Nl2SqlAccuracyGoldenSetReleaseEvidenceService`，输出 `runId`、`generatedAt`、release gate、失败摘要和弱路径来源。
- `it/test_sprint34_accuracy_plan.sh` 纳入黄金集资源、scorecard 和 release evidence 测试类检查。
