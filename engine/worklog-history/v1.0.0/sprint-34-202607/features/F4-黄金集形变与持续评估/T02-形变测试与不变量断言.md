# T02: 形变测试与不变量断言

**优先级**: P1
**状态**: DONE
**依赖**: T01

## 目标

用“同义问法、时间变体、维度变体、过滤条件变体”证明 NL2SQL 不是只对单句样例正确。

## 技术设计

- 同义问法：统计/汇总/看下/数据情况。
- 时间变体：今年、去年、2026年、2026年度。
- 过滤变体：月份、业务类型、状态、项目。
- 不变量：同一指标在不同表达下目标表和口径不变。

## 影响范围

- template matcher parameter extraction tests。
- semantic guardrail tests。
- `Nl2SqlAccuracyGoldenSetScorecardService`。

## 落地结果

- `finance-voucher-yearly-2026` 形变组要求 `2026年凭证的数据统计下` 和 `看下2026年度会计凭证汇总` 保持同一模板、同一目标表、同一年份参数。
- scorecard 会在运行结果漂移到其他模板或其他 target 时输出 `metamorphic drift` 失败原因。

## 验证

- [x] `2026年凭证的数据统计下` 与 `看下2026年度会计凭证汇总` 命中同一模板。
- [x] 时间参数一致。
- [x] 目标 relation 不漂移。

## 完成标准

- [x] 形变测试能发现模板漂移和参数抽取错误。
