# F5: 可信解释与低可信交互

**优先级**: P1
**状态**: DONE

## 目标

让用户在界面上看到“这个结果为什么可信/为什么不可信”，并在低可信时引导补充条件、构建模型或执行对账。

## Task 列表

| ID | Task | 优先级 | 状态 | 依赖 |
|----|------|--------|------|------|
| T01 | 可信度证据面板 | P1 | DONE | F1-T03 |
| T02 | 低可信降级与追问 | P1 | DONE | T01 |
| T03 | 用户文案与 IT 证据包 | P2 | DONE | T02 |

## 完成标准

- [x] 回答卡展示可信等级、数据来源、缺失证据。
- [x] 低可信结果不包装成确定结论。
- [x] 用户能看到下一步建议。
