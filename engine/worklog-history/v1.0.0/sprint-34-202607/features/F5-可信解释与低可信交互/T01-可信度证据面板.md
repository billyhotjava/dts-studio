# T01: 可信度证据面板

**优先级**: P1
**状态**: DONE
**依赖**: F1-T03

## 目标

在 Agent-First 结果面展示 NL2SQL 结果可信度和证据摘要。

## 技术设计

- 展示字段：可信等级、数据来源、模板/指标、目标表、最后构建时间、对账状态。
- HIGH 绿色，MEDIUM 黄色，LOW/UNTRUSTED 明确提示。
- SQL 仍可展开，但证据摘要优先于 SQL。

## 影响范围

- Copilot chat result artifact。
- trust/source panel。
- 前端 contract tests。

## 验证

- [x] HIGH 结果展示“可用于经营判断”。
- [x] MEDIUM 展示缺失对账证据。
- [x] UNTRUSTED 不展示为统计结论。

## 完成标准

- [x] 用户不用读 SQL 也能理解数据可信度。
