# T02: 评分服务与硬降级规则

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标

实现 `AccuracyEvidenceScorer`，根据路由、SQL、数据新鲜度、对账结果输出可信等级和原因。

## 技术设计

- 评分维度：意图解析、数据层、SQL 安全、数据新鲜度、对账证明。
- 硬降级规则：
  - L0 profile 最高 `LOW`。
  - 应用 MySQL 直连最高 `LOW`。
  - ADS/DWS 未构建或入湖缺失为 `UNTRUSTED`。
  - SQL static check 不通过为 `UNTRUSTED`。
  - 无对账证据的 ADS/DWS 最高 `MEDIUM`。

## 影响范围

- NL2SQL planning/response service。
- Route telemetry 到 evidence 的映射。
- 单元测试。
