# T01: 证据契约与等级定义

**优先级**: P0
**状态**: DONE
**依赖**: 无

## 目标

把“意图正确、口径正确、数据层正确、模型正确、结果可对账”固化为 `accuracyEvidence` 后端契约。

## 技术设计

- 新增 DTO/contract test，字段参考 `assets/nl2sql-accuracy-evidence-contract.v1.md`。
- 字段分组：`intent`、`route`、`sql`、`data`、`tieout`、`grade`、`score`、`reasons`、`warnings`。
- `grade` 只允许 `HIGH`、`MEDIUM`、`LOW`、`UNTRUSTED`。

## 影响范围

- `dts-copilot-ai` 的 chat contract。
- `CopilotChatContract` 或等价响应协议。
- contract/unit tests。

## 验证

- [x] contract test 覆盖四个等级枚举。
- [x] 缺少 evidence 时默认 `UNTRUSTED` 或 `LOW`，不能默认高可信。

## 完成标准

- [x] 契约字段、枚举、示例 JSON 成文并有测试锁定。
