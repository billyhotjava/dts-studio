# T01: 三源口径差异盘点（finance + procurement）

**优先级**: P0
**状态**: READY
**依赖**: 无

## 目标

对 finance、procurement 两域的每条口径规则，逐条比对三处定义是否一致，输出差异台账，作为定源（T02）与 ADR（T04）的事实输入。

## 技术设计

盘点三处来源：
1. **copilot pack**：`dts-copilot-ai/src/main/resources/semantic-packs/finance.json`、`procurement.json` 的 `guardrails` / `fewShots` / 业务对象口径。
2. **dbt mart**：dts-stack `services/dts-dbt/models/{dwd,dws,ads}/` 中 `xycyl_*` 财务/采购模型物化的口径（结算链拆分、三级金额列、枚举展开）。
3. **glossary / 数据标准**：dts-platform `modeling`（`ModelingGlossaryTerm` / `DataStandard`）+ OpenMetadata Glossary。

对照锚点 = 9 条口径铁律（`reference_xycyl_caliber_traps`）：逐条记录三源对该铁律的表达，标注 一致 / 漂移 / 缺失。

产出 `assets/caliber-source-diff-matrix.md`：列 = [铁律编号, 规则描述, pack 表达, dbt 表达, glossary 表达, 是否漂移, 备注]。

## 影响范围

- 产出 `assets/caliber-source-diff-matrix.md`
