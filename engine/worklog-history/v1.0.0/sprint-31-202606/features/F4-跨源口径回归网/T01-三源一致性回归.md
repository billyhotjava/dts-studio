# T01: 三源一致性回归

**优先级**: P1
**状态**: READY
**依赖**: F2-T02, F1-T03

## 目标

用自动化测试持续验证 pack 生成区、dbt mart 口径、glossary 三者在可比维度上一致，任一漂移即红。

## 技术设计

- 以治理层 SoT 为基准，断言：
  1. pack 生成区 guardrails == 由 SoT 生成的期望（F2-T02 生成器幂等性）。
  2. dbt mart 关键口径列/模型与 SoT 对象定义一致（如结算链拆分、三级金额列存在且语义对齐）——以元数据/manifest 比对，必要时 dbt test。
  3. glossary term 与 SoT 对象/术语一致（OpenMetadata 拉取比对）。
- 不可纯静态比对的维度，退化为"存在性 + 关键属性"断言并记录已知差异白名单。

## 影响范围

- `dts-copilot-ai` 测试 + 可能的 dts-stack dbt test/比对脚本
- 产出回归用例 + CI 接入说明

## 验证

- [ ] 故意改一处 pack 生成区 → 回归红
- [ ] 三源当前状态回归绿

## 完成标准

- [ ] 三源一致性回归稳定可跑、可入 CI
