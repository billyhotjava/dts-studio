# T01: 治理层口径/指标定义导出契约

**优先级**: P0
**状态**: DONE
**依赖**: F1-T02, F1-T03

## 目标

在治理层提供稳定的导出接口/制品，把口径主数据（规则 + 对象/列口径 + 指标定义）以版本化、机器可消费的形式输出，供 copilot 生成 pack。

## 技术设计

两种形态二选一（T04 ADR 倾向）：
- **API 形态**：dts-platform 暴露 `/api/governance/caliber-rules`、`/api/governance/indicators`（指标已有，sprint-29），返回口径规则 + 对象口径，带 `version` / `etag`。
- **制品形态**：复用 `bin/export-dbt-artifacts.sh` 范式，导出 `caliber-rules.json` + `semantic-objects.json` tarball，随部署分发。

契约要点：
- 版本化（语义版本 + 内容哈希），便于 T03 漂移检测与回滚。
- 按 `CatalogDomain` 域过滤，支持多域分别拉取（为 Sprint-32 多场景铺路）。
- 输出 schema 对齐 F1-T02 主数据模型。
