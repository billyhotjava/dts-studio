# T04: 4 个一级入口导航重构

**优先级**: P0
**状态**: READY
**依赖**: T01, T03

## 目标

按 spec §4「极细左导航（4 个一级图标）」与 §5「收口后一级入口仅 4 个」，把左侧一级导航重构为「＋新对话 / 💬历史会话 / 📁资产库 / 🔔信号」四项；治理后台（data/models/metrics/admin）从一级导航收进右上角，按 `privileged/superuser` 控制可见（决策 D5）。

## 技术设计

1. **重写 `PRIMARY_NAV_SECTIONS`**（`dts-copilot-webapp/src/layouts/appNavigation.ts`）：
   - 现状 `core` 段为 `agentReports`(/agent-bi) + `dashboards`，`data` 段为 `dataSources`。改为单一 `core` 段含四项一级入口：
     - `newChat` → `/agent-bi`（＋新对话，进入工作台冷启动；`end: true`）
     - `chatHistory` → `/agent-bi/sessions`（💬历史会话；路由壳归属 F3，本 Task 先占位 `to`，若该路由 F3 未就绪则指向工作台并标注 TODO）
     - `assets` → `/assets`（📁资产库；F7 提供，本 Task 占位 `to`，落地前可临时指向 `/dashboards`）
     - `signals` → `/signals`（🔔信号；P3/信号 Feature 提供，本 Task 占位 `to`）
   - 一级入口 `visibility` 设为 `"all"`（业务用户均可见）。
   - 占位路由用注释标明依赖 Feature，避免 404：未就绪者先指向工作台或资产页，待对应 Feature 接管。

2. **治理后台收进右上角**：
   - 现有 `data` 段（`dataSources`，`visibility:"superuser"`）从 `PRIMARY_NAV_SECTIONS` 移除，并入 `ADMIN_NAV_ITEMS`：新增 `dataSources`(/data)、并保留/补充 `models`(/models)、`metrics`(/metrics)，与既有 `users`(/admin/users)、`systemSettings`(/admin/settings/copilot) 一并归入治理后台。
   - 治理项渲染位置：从左导航段改为 `AppLayout` 右上角（`main-header__right`）的「⚙治理后台」入口（spec §4「管理员右上角多一个 ⚙治理后台」）。在 `AppLayout.tsx` 中用 `Dropdown` 展开治理菜单，复用 `getVisibleNavigation` / `canSeeItem` 的 `privileged/superuser` 过滤逻辑。
   - 可见性：治理项保持 `superuser`（或对治理读权限放宽到 `privileged`，按 `resolvePrivilegedAccess` 现有口径）；非授权用户右上角不显示治理入口。

3. **图标**（`dts-copilot-webapp/src/layouts/AppLayout.icons.tsx` + `appNavigation.ts` 的 `NavigationIconKey`）：
   - 扩展 `NavigationIconKey` 联合类型：新增 `newChat | chatHistory | assets | signals | governance`，移除/保留旧 key（`agentReports`、`dashboards` 等按需保留给治理菜单/资产页复用）。
   - 在 `AppLayout.icons.tsx` 新增对应图标组件（沿用现有 20×20 stroke SVG 风格、`role="img"` + `aria-label`）：新对话(＋)、历史会话(💬/列表)、资产库(📁/文件夹，可复用 `CollectionIcon`)、信号(🔔/铃铛)、治理(⚙，可复用 `SettingsIcon`)。
   - 同步 `AppLayout.tsx` 的 `getNavigationIcon` switch 分支覆盖新 key。

4. **清理 `HIDDEN_LEGACY_NAV_IDS`**：
   - 现含 `models/metrics/trash/analyze/questions/collections/exploreSessions/reportFactory/fixedReports/screens/metricLens/search`。
   - T01 已删除 `analyze/exploreSessions/reportFactory/metricLens` 对应页面 —— 从隐藏清单移除这些已不存在的 id（它们已无导航项可隐藏）。
   - `models/metrics` 移入治理后台后从隐藏清单移除；`questions/collections/screens/trash/search` 视 F7 资产库收口情况保留隐藏或下沉资产库（本 Task 仅维护清单与新结构一致，资产库二级入口归 F7）。

5. **`MOBILE_NAV_ITEMS`**：现引用 `PRIMARY_NAV_SECTIONS[0].items[0]/[1]` 与 `[1]` 段，重构后下标失效，需重写为新四项中适配移动端的子集（如 新对话 / 历史会话 / 资产库 / 信号）。同步 `MobileTabBar` 消费。

6. **更新测试**（`dts-copilot-webapp/src/layouts/appNavigation.test.ts`）：
   - 现有断言 `visibleIds` 等于 `["agentReports","dashboards","dataSources","users","systemSettings"]`、非特权用户为 `["agentReports","dashboards"]`，均已过时。
   - 重写为：特权/超管用户一级入口为四项 `["newChat","chatHistory","assets","signals"]`（治理项不再属 `getVisibleNavigation` 的左导航返回，或单列治理段断言）；非特权业务用户同样可见四项一级入口；治理项仅 `superuser/privileged` 可见。
   - 更新「不暴露未完成 Metabase 克隆页」断言以对齐新的 `HIDDEN_LEGACY_NAV_IDS`。
