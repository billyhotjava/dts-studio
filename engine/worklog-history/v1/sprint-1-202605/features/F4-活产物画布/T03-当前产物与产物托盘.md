# T03: 当前产物 + 产物托盘(ArtifactTray)

**优先级**: P0
**状态**: READY
**依赖**: T01, T02

## 目标

把 `ArtifactCanvas`(T02)与 `useArtifactStore`(T01)组装成完整的右侧画布:**画布主区显示「当前产物」,会话历史产物收进底部「产物托盘」,点击托盘项把任一历史产物切回画布**;追问产生新产物时画布原地切换、旧产物入托盘不丢失。落实决策 D6「默认只显示当前产物,不平铺」。

## 技术设计

### 1. 容器组件(新建 `src/components/canvas/CanvasPanel.tsx`)

画布面板根容器,纵向布局:顶部动作行(T04 `CanvasActions` 插槽)→ 中部 `ArtifactCanvas`(当前产物)→ 底部 `ArtifactTray`(托盘)。从 `useArtifactStore` 取 `current` / `artifacts` / `setCurrent`。

```tsx
interface CanvasPanelProps {
  store: ArtifactStore;                 // 由上层(F5/工作台)注入,会话切换时 clear
  loading?: boolean;
  error?: unknown;
  onArtifactAction?: (action: CanvasActionType, artifact: Artifact) => void; // 透传给 T04
}
```

### 2. 产物托盘(新建 `src/components/canvas/ArtifactTray.tsx`)

```tsx
interface ArtifactTrayProps {
  artifacts: Artifact[];        // store.artifacts,按 createdAt 升序
  currentId: string | null;
  onSelect: (id: string) => void;
}
```

- 横向滚动条形托盘,每个产物一个缩略 chip:小图标(按 `type`:📈chart / ▦table / 📄report)+ `title`(默认取 message 问题或报表名)+ 序号。
- 当前产物 chip 高亮(对齐 `currentId`)。
- 点击 chip → `onSelect(id)` → `store.setCurrent(id)` → 画布切回该历史产物。
- 仅 1 个产物时托盘可隐藏或弱显示(避免空占位);产物数多时横向滚动(不平铺、不堆叠,符合 D6)。
- 键盘可达:chip 为 `button`,支持左右方向键切换 + Enter 选中(对齐用户全局可访问性规则)。

### 3. 「原地演化」与「入托盘」语义

- **追问产生新产物**:F5 调用 `store.upsert(newArtifact)`(新 `id`)→ store 自动 `setCurrent(newArtifact.id)` → 画布原地换成新产物,旧产物留在 `artifacts` 中、出现在托盘可切回。
- **同一产物被修订**(如换可视化类型):F5 用相同 `id` `upsert` → 原地更新,不新增托盘项。
- 切回历史产物只改 `currentId`,不改 `artifacts` 顺序,不丢任何产物。

### 4. 与 store 的连接

`CanvasPanel` 不持有自己的产物状态,全部读自传入的 `store`(单一数据源)。store 的生命周期由上层(F5 工作台页)管理:进入会话创建、切换会话 `clear()`。这保证画布与对话通过 store + `artifactId` 解耦连接,而非组件间直接传消息。

## 验证

- [ ] 单产物:画布显示该产物,托盘弱显示或隐藏。
- [ ] 连续追问产生多产物:画布始终显示最新,旧产物按序进入托盘。
- [ ] 点击托盘任一历史 chip:画布切回该产物,chip 高亮随之更新,其余产物不丢。
- [ ] 同 `id` `upsert`:画布原地更新,托盘项数不变。
- [ ] 托盘 chip 键盘可达(Tab 进入、方向键/Enter 切换)。
- [ ] `clear()` 后画布回到无产物占位、托盘清空。
- [ ] `ArtifactTray.test.tsx` / `CanvasPanel.test.tsx` 覆盖切换、原地演化、清空。
