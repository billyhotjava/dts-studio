# T02: 语音入口接入

**优先级**: P0
**状态**: READY
**依赖**: T01（大输入框已落地）

## 目标

把现有 `VoiceInputButton` 接到冷启动首屏的大输入框：点按录音，语音转写文本回填到输入框，用户可直接发送。语音是对话主轴的关键入口（设计决策 D2），首屏必须一等公民支持。

## 技术设计

- 在 `ColdStartComposer.tsx`（T01）的输入框右下角操作区渲染 `<VoiceInputButton onTranscript={...} disabled={...} />`（复用 `src/components/copilot/VoiceInputButton.tsx`，底层 `useVoiceInput`，已配置 `lang: "zh-CN"`、`continuous: false`、`interimResults: true`、`maxDuration: 30`）。
- **转写回填逻辑**（参考 `CopilotChat.tsx` 第 1356 行的接法）：
  - `onTranscript(text, isFinal)`：
    - 中间结果（`isFinal === false`）：实时更新输入框显示为「已有文本 + 当前中间文本」的预览，不入正式 state（避免 interim 文本污染可编辑值），用一个 `interimRef` / 局部 state 区分。
    - 最终结果（`isFinal === true`）：把最终文本追加/合并进受控 `value`（不可变更新 `setValue(prev => mergeTranscript(prev, text))`），交由用户编辑或直接发送。
  - 提取纯函数 `mergeTranscript(existing: string, transcript: string): string` 便于单测（处理前导空白、空 existing、重复片段）。
- 录音进行中（`state === "listening"`）时输入框给出可视提示（如边框/占位变化），不阻塞键盘输入。
- 语音不支持的浏览器：`VoiceInputButton` 在 `isSupported === false` 时自身返回 `null`，首屏需保证此时大输入框与发送布局不塌陷（按钮缺位时布局优雅降级）。
- 不修改 `VoiceInputButton.tsx` 内部实现（纯复用）；如发现需要新增 prop 才记入影响范围。

## 影响范围

- 修改：`src/components/copilot/cold-start/ColdStartComposer.tsx`（接入语音按钮 + 转写回填）。
- 新增：`mergeTranscript` 工具（可置于 `cold-start/coldStartComposerModel.ts`）+ 其单测。
- 复用（不改）：`src/components/copilot/VoiceInputButton.tsx`、`src/hooks/useVoiceInput.ts`。

- [ ] 点按开始录音 → 中间结果实时预览 → 最终结果回填输入框，可继续编辑或直接发送。

- [ ] 不支持语音的环境下按钮不渲染，输入框/发送布局不塌陷。
- [ ] vitest：`mergeTranscript` 纯函数单测（空 existing、追加、前后空白）；首屏渲染含语音按钮槽位（mock `useVoiceInput`）。
