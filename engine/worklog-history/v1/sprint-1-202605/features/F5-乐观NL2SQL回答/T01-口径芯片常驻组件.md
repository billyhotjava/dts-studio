# T01: 假设/口径芯片组件(常驻)

**优先级**: P0
**状态**: READY
**依赖**: F3(对话脊柱消息渲染就绪)、F4(产物引用接口,改后重算回调在 T04 落地)

## 目标

新建 `EditableAssumptionChips` 组件,常驻在每条 assistant 结果卡顶部,把 agent 推断出的关键口径假设渲染成一排可点改芯片(如「本月=2026-05 ✎」「利润=收入−成本 ✎」「范围=在租项目 ✎」),点击单个芯片进入编辑态,提交后通过回调上抛新假设(实际重算在 T04)。本 Task 只做**组件 + 类型 + 结果卡集成 + 编辑交互**,不做发送/重算逻辑。

> 设计依据:spec D8(关键口径常驻结果卡,方便新手)、§6 结果卡构成「常驻口径芯片 + 图表/表格 + 动作行」。

## 技术设计

- **类型契约**(新建 `src/components/copilot/assumptions/assumptionTypes.ts`):
  ```ts
  // 单条可改假设/口径
  export interface CopilotAssumption {
    key: string;            // 稳定标识,如 "period" / "profitFormula" / "scope"
    label: string;          // 展示标签,如 "本月"
    value: string;          // 当前取值文本,如 "2026-05"
    editable?: boolean;     // 默认 true;不可改口径(如硬性本体定义)置 false 仅展示
    options?: { value: string; label: string }[]; // 给定可选项 → 编辑用 select;否则用文本输入
    sourceHint?: string;    // 可选:口径来源提示(本体/版本),供 hover/溯源衔接 F6
  }
  ```
  在 `src/api/types.ts` 同步给 `AiAgentChatMessage` 增 `assumptions?: CopilotAssumption[]`(契约扩展,详见 T02 的接口扩展)。
- **组件**(新建 `src/components/copilot/assumptions/EditableAssumptionChips.tsx`):
  - Props:`{ assumptions: CopilotAssumption[]; onCommit: (key: string, nextValue: string) => void; disabled?: boolean }`。
  - 渲染一排 `<button type="button">` 芯片,文本 `「{label}={value}」`,可改芯片尾部带 `✎` 编辑标记(`editable !== false`);不可改芯片无标记、`aria-disabled`。
  - 点击可改芯片 → 进入**单芯片编辑态**(局部 state `editingKey`):有 `options` 渲染 `select`,否则渲染文本 `input`;回车/失焦/「确定」提交,Esc/「取消」回退。提交时若值有变化才调 `onCommit(key, nextValue)`;无变化不触发。
  - 受控编辑值用组件内部 state,提交后由父层更新 `assumptions` 回流(单向数据流,不就地 mutate 入参)。
  - `disabled` 时(如重算进行中)芯片整体不可点,避免重复触发。
- **纯函数**(`assumptionTypes.ts` 内或同目录 `assumptionChipsModel.ts`):
  - `formatAssumptionChipLabel(a: CopilotAssumption): string` → `"本月=2026-05"`。
  - `hasAssumptionChanged(a: CopilotAssumption, nextValue: string): boolean` → 去空白比较,便于单测且供 onCommit 守卫。
- **结果卡集成**:在 `CopilotChat.tsx`(F3 拆分后对应 `MessageList` / 消息渲染单元)的 assistant 结果卡区域,在 `generatedReportNotice` / `InlineSqlPreview` **之上**渲染 `EditableAssumptionChips`(仅当 `msg.assumptions?.length` 时)。`onCommit` 在本 Task 先接一个 noop / 上抛占位回调(由 T04 替换为重算)。
- **样式**:新建 `EditableAssumptionChips.css`,芯片有 hover/focus/active 设计态(非默认按钮样式),编辑态 input/select 与芯片对齐;`✎` 用文本符号或内联 svg,避免引第三方图标依赖。
